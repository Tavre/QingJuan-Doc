# 青卷 V2.3.0 更新日志

## 书库与内容发现

- 新增站点推荐与排行榜浏览、作品预览，以及可恢复的多链接导入历史。
- 书库支持分组、标签、置顶、阅读状态和作品信息编辑，并加入连载检查与自动下载新章节。

## 阅读与听书

- 新增书签、划线笔记、章内及已缓存正文搜索。
- Android 支持选章离线阅读、联网后同步进度和冲突处理；听书增加独立进度、定时停止及通知栏和锁屏控制。

## 翻译与插件

- 小说新增术语表、人名映射、译文校对、历史恢复、选段重译和模型用量记录。
- 插件管理增加自检、兼容性检查和上一版本回退，并继续加固站点、模型端点与 Fake-IP 网络边界。

## 数据与管理

- 新增完整书库备份、校验、恢复及 Windows 本机书库向空 Linux 服务端的显式迁移。
- 增加书籍占用统计、导出文件清理、用户存储与模型请求额度、公平任务调度，以及账号改密、邮箱找回和会话管理。

应用版本：`2.3.0+44`；发布标签：`v2.3.0`。
