# 青卷 V2.2.0 更新日志（发布候选）

v2.2.0 是一次跨客户端、后端与发布链路的功能更新。它带来客户端在线更新和 Windows 安装器，让 Android 可以在同一局域网内扫描二维码连接 PC 本机后端，并开放可安装的站点插件包。同时改进站点登录与导入、桌面工作区和 Linux 管理端控制能力。

## 客户端在线更新

- Windows 与 Android 每次启动都会独立检查 GitHub Releases 正式版，检查过程不依赖后端是否连接或用户是否登录；网络不可用不会阻止进入书架，稍后可手动重试。
- 更新源、关于页和下载地址统一迁移到 `qingscroll/QingJuan`。客户端只接受官方仓库中格式为 `v主版本.次版本.修订号` 的正式 Release，不把构建号视为新版本，也不会自动降级。
- Windows 在 **设置 → 软件更新** 显示当前版本、新版说明和检查时间，并提供检查、下载、取消、重试、打开发布页面及“退出并安装”。
- Windows 只下载与目标版本严格匹配的 `QingJuan-v<版本>-windows-x64-setup.exe` 及同名 `.sha256`，校验 Release 归属、文件名、大小和 SHA-256；下载完成和启动安装器前各校验一次，失败时不会执行文件。
- Android 在 **我的 → 软件更新** 检查版本并通过浏览器下载官方 APK，安装确认继续交给 Android 系统，不进行静默安装。
- 首个包含在线更新能力的版本仍需手动安装；从后续版本起才可在客户端内完成完整更新流程。

## Windows 安装器与更小的发布包

- 新增 Windows x64 安装程序 `QingJuan-v<版本>-windows-x64-setup.exe`，默认按当前用户安装到 `%LOCALAPPDATA%\Programs\QingJuan`，无需管理员权限。
- 安装向导提供开始菜单入口、可选桌面快捷方式和系统卸载入口；仍保留免安装 ZIP，用户可按习惯选择。
- 覆盖安装沿用当前目录并保留 `backend/data/`；卸载只移除程序清单中的文件，同样保留书库与设置。旧 ZIP 用户需要选择原目录安装，安装到新目录不会自动搬运旧数据。
- 点击“退出并安装”前会提示本机下载、翻译和未保存编辑可能中断；安装器等待当前客户端退出后才覆盖文件，并通过单实例互斥避免安装或卸载时修改正在运行的程序。
- Windows 本机后端从单文件改为目录式打包，移除未使用的视频、GUI 和自测依赖，并统一压缩。安装 EXE 在本地对比中约缩小 32%，启动时不再反复把大型后端解包到临时目录。
- 离线 OCR 模型、图片格式、PDF、AES、HTTPS 公共 CA 和现有本机后端能力继续保留，并由冻结后端冒烟测试验证。
- Release 流水线扩展为六个资产：Windows ZIP、Windows 安装 EXE、Android APK，以及三份对应的 SHA-256 文件。

## 手机扫码连接 PC

- Windows **设置 → 手机连接** 可把当前后端生成成二维码或连接链接；Android 在 **我的 → 服务连接** 中扫码、粘贴链接并在核对地址后连接。
- Windows 使用本机后端时，可选择内网网卡并开启 TCP `19454` 的受保护共享入口。手机和电脑处于同一局域网时，Android 可直接使用 PC 的书库、任务、翻译模型和阅读进度，无需部署 Linux，也无需另建用户账号。
- 使用期间 PC 青卷必须保持运行；关闭共享、切换 PC 到远程后端或退出应用后，局域网入口失效。重新生成二维码会轮换连接密钥，手机需要重新扫码。
- Windows 已连接 Linux 远程后端时，二维码分享当前保存的服务地址和连接 Token；Android 连接后仍需登录对应青卷账号，同一账号才能看到同一份远程书库。
- 连接凭据不会放入 URL 查询参数；局域网桥接限制允许访问的 API 路径、上游地址和重定向。二维码和连接链接仍属于敏感凭据，只应交给可信设备。

## 可安装的站点插件包

- 支持将独立 Python 解析器打包为 `.qjplugin` 或 `.zip`，无需修改青卷内置注册表或重新发布客户端，即可向当前后端增加作品预览、章节、搜索和按需下载能力。
- Windows 本机模式可在 **插件配置 → 导入插件** 安装；Linux 远程后端由管理员在 `/admin/#plugins` 中预检、安装、更新和卸载。内置插件仍只能启停。
- 搜索页新增 **导入插件** 引擎，同时查询已安装且声明搜索能力的插件；Windows 与 Android 都能使用当前后端已经安装的插件。
- 导入前展示插件 ID、版本、作者声明、域名和能力，并要求用户确认信任来源。更新必须使用同 ID 的更高版本，安装失败会保留旧包和原运行实例，停用状态也会保留。
- 插件包和状态保存在当前后端 SQLite 中；启动时校验摘要并逐个加载，单个包损坏只会将该插件标记为不可用，不阻止后端启动。
- v1 插件包只允许根目录下的 `manifest.json` 与 `plugin.py`，限制包体、解压大小、域名和返回数据；网络 SDK 检查目标域名、公网地址与重定向，并设置请求次数、响应大小和协作式超时上限。
- Python 插件在后端进程内运行，不是安全沙箱。作者字段与 SHA-256 不能证明代码可信，必须只安装来源可信且经过审查的插件；v1 不提供 pip 自动依赖、多文件资源、插件市场、自动升级或插件账号登录扩展。

## 站点搜索、登录与导入

- 搜索页新增 **笔趣阁** 直接引擎，优先使用八零小说网搜索，并聚合笔趣阁 5200 与笔趣看等可用镜像目录；加入目录缓存、结果短缓存、失败冷却、编码处理和稳定 URL 归一化。
- 少年梦解析器升级到 `1.1.0`，新增账号登录入口。用户在青卷打开的受控浏览器页面中输入少年梦账号并完成人机验证，登录状态按后端用户隔离且只保存在进程内存；退出或后端重启后清除。
- 18Comic 导入支持直接填写纯数字“禁漫本子号”，自动识别为漫画并获取对应专辑、章节和图片；也继续支持完整专辑链接。输入会校验为正整数，并拒绝与编号不一致或不可信的链接。
- 桌面和移动端导入表单会根据禁漫本子号锁定漫画类型与全部下载模式，避免把专辑编号误当章节编号。

## 桌面与移动端体验

- Windows Shell 与书架页面拆分为独立桌面组件，继续保持 Fluent 宽屏布局；书架增加搜索书名或简介、最近阅读区、刷新入口和更清晰的空状态、链接任务及添加书籍操作。
- 标题栏继续提供托盘、最小化、最大化和关闭，并强化状态反馈与单实例行为，为安装器安全退出提供基础。
- Android 服务连接面板增加扫码入口和应用链接接收；本地文件、作品链接与禁漫本子号在移动端使用清晰的分步导入入口。
- 更新页、共享连接、插件管理和站点登录均提供加载、失败、取消或重试反馈，并保持桌面与移动端各自的交互密度。

## Linux 管理与运行控制

- 管理界面 **服务概览** 新增业务服务状态、代次，以及开启、关闭和重启操作。
- 关闭业务服务后，客户端业务请求与新队列任务暂停，当前任务安全结束；管理通道保持在线，因此管理员无需退出页面即可重新开启服务。
- 启停和重启要求管理会话，写操作继续校验 CSRF，并在有活动任务时明确提示影响。

## 兼容性、安全与验证

- 现有 Windows 本机数据、Linux 多用户数据、书库、阅读进度和连接配置不需要手工迁移；安装或更新前仍建议备份当前后端数据。
- Android 仍不内置 Python 后端；“连接 PC”是访问 Windows 正在运行的受保护 FastAPI 共享入口，而不是在手机上运行后端。
- 在线更新请求不会携带青卷后端 Token；取消或失败下载会清理临时文件。SHA-256 用于完整性检查，不等同于 Windows 代码签名。
- 当前发布 PR 已通过 403 项 Flutter 测试、568 项 Python 测试、62 项管理界面测试，并完成 Dart 格式、源码范围分析、Ruff 与管理端生产构建。
