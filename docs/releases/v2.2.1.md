# 青卷 V2.2.1 更新日志

- 修复启用 TUN / Fake-IP DNS 的代理环境中，站点域名解析到 `198.18.0.0/15` 后抓取请求被安全策略拒绝的问题。
- 检测到 Fake-IP 时改用加密 DNS 获取真实公网地址，同时保留 HTTPS 域名校验和连接地址固定。
- 加密 DNS 不继承系统代理、不跟随重定向；私网、环回、链路本地、Fake-IP 和混合不安全结果仍会被拒绝。
- 无法取得安全的公网解析结果时继续默认拒绝，并提示检查代理 DNS 模式。

应用版本：`2.2.1+43`；发布标签：`v2.2.1`。[查看 GitHub Release](https://github.com/qingscroll/QingJuan/releases/tag/v2.2.1)
