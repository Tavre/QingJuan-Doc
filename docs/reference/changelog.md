# 版本记录

## v1.6.0

发布于 2026-08-17（中国标准时间）。[查看 Release](https://github.com/Tavre/QingJuan/releases/tag/v1.6.0)

### 站点插件与账号书架

- 将番茄、起点、Kakuyomu、Yanmaga 等 20 个内置站点解析器统一为可声明域名、作品类型、能力和启停状态的插件；
- Windows 本机模式在客户端 **插件配置** 中管理，Linux 远程后端在 `/admin/#plugins` 管理，Android 由服务器管理员维护；
- 番茄与起点支持扫码登录和一键添加当前账号书架；番茄扫码不可用时可改用 Cookie 登录；
- 书架导入跨分组和分页去重、跳过已有作品、显示进度与结果统计，并以“边看边下”模式添加文字作品；
- Cookie、会话与站点账号信息只保存在当前后端进程内存中，后端重启后需要重新登录；
- 内置插件与 Legado / 阅读 App JSON 书源继续保持独立。

### 客户端界面、动效与性能

- Windows 新增自绘标题栏、可折叠和拖拽调宽的导航栏、键盘导航快捷键与本机插件配置工作区；
- Android 保持触控优先的移动端导航与安全区适配，不包含本机 Python 后端；
- 统一页面切换、按压、选择和阅读控制层动效，系统请求减少动态效果时自动切换为零时长；
- 减少无效背景模糊与重复重绘，为长列表和复杂静态区域增加重绘隔离；
- 重新整理书架、搜索、详情、阅读、听书、任务、书源和设置页面的响应式层级。

### 后端与发布

- FastAPI 新增插件清单、启停、登录、书架预览和异步导入接口；
- Linux 管理界面新增插件搜索、筛选、详情、启停、登录与账号书架操作；
- 首次启动自动创建插件启停设置表并填充默认状态，不覆盖现有书库、进度、任务或连接配置；
- Flutter 格式、分析、119 项测试与 Android Release 构建通过；Python Ruff、Compileall 与 178 项后端测试通过；管理界面类型检查、25 项测试和生产构建通过；
- 正式 Release 提供 Windows x64 ZIP、Android APK 与两份 SHA-256 校验文件。

### 升级说明

- v1.6.0 可直接读取 v1.5.0 的 Windows 本机或 Linux 后端数据，升级前仍建议备份数据目录；
- `v1.5.1` 未正式发布，其设置页拆分和管理界面主题调整已合并到 v1.6.0。

## v1.5.0

发布于 2026-08-13（中国标准时间）。[查看 Release](https://github.com/Tavre/QingJuan/releases/tag/v1.5.0)

### Windows 本机与 Linux 远程双后端

- Windows ZIP 恢复随包本机 FastAPI 后端，可在“本机后端”和“Linux 远程后端”之间显式选择；
- 本机模式固定监听 `127.0.0.1:19453`，无需 Linux 服务器、连接 Token 或单独安装 Python；
- 本机与远程连接档案独立保存，切换模式不会覆盖远程地址与 Token；
- Windows 本机数据与 Linux 数据不会自动同步；
- Android 继续保持远程客户端边界，不包含或启动本机 Python 后端。

### 管理与构建

- 新增随后端同源提供的 React 管理界面、系统诊断、脱敏报告、结构化日志和翻译模型自检；
- Windows 发布包重新包含 `backend/qingjuan-desktop.exe`，并检查版本、管理静态资源和敏感文件边界；
- 从 v1.4 升级的 Windows 用户会保留既有远程配置，需要单机使用时可在设置中手动选择“本机后端”。

## v1.4.0

发布于 2026-08-12（中国标准时间）。[查看 Release](https://github.com/Tavre/QingJuan/releases/tag/v1.4.0)

### Windows 与 Android 共用远端后端

- 新增 Flutter Android 客户端；
- Windows 与 Android 共用 Linux 书库、任务和 API；
- 客户端不再启动本地 Python；
- 新增远端地址校验、连接状态和安全 Token 存储。

### 阅读器与界面

- 新增左右分页、连续滚动、章节预取和多种翻页效果；
- 增加纸张、护眼、淡蓝和夜间配色；
- 支持字号、行距、原文/译文、章节目录和进度跳转；
- Android 增加系统文件保存、TTS 声线扫描、音量键阅读和沉浸式系统栏；
- 统一 Windows/Android 的阅读产品视觉，并覆盖窄屏、长标题、200% 文字缩放和减少动态效果。

### 构建与迁移

- CI 同时检查和构建 Windows、Android 与 Linux 远端后端；
- 正式发布提供 Windows ZIP、Android APK 和两份 SHA-256；
- 本次不修改 Linux 数据库结构和书籍数据格式；
- 升级后必须配置 Linux 后端，不提供本地 Python 回退。
