## v2.2.0

发布于 2026-09-11，版本号为 `2.2.0+42`。[查看完整更新说明](../releases/v2.2.0.md) · [查看 Release](https://github.com/qingscroll/QingJuan/releases/tag/v2.2.0)

### 更新与安装

- Windows 与 Android 启动后独立检查官方正式 Release；Windows 可下载、校验并退出安装，Android 打开官方 APK 下载；
- Windows 新增当前用户安装器，提供开始菜单、可选桌面快捷方式和卸载入口，覆盖安装与卸载均保留 `backend/data/`；
- Windows 本机后端改为目录式打包并精简依赖，安装 EXE 在本地对比中约缩小 32%；发布流水线扩展为三个主文件和三份 SHA-256。

### PC 与手机连接

- Windows 可生成当前后端的二维码与连接链接；Android 支持扫码或粘贴链接；
- 本机模式可通过受保护的 TCP `19454` 局域网入口共享 PC 书库，Android 无需 Linux 或独立账号；
- 远程模式二维码分享 Linux 地址与 Token，Android 仍需登录同一账号；连接凭据不写入 URL 查询参数。

### 插件与站点

- 新增 `.qjplugin` / `.zip` 站点插件包，可预检、安装、更新、启停、卸载，并在 Windows 与 Android 的 **导入插件** 搜索引擎中使用；
- 新增笔趣阁聚合搜索，覆盖八零小说网、笔趣阁 5200 与笔趣看；
- 少年梦新增受控浏览器账号登录，18Comic 支持直接输入禁漫本子号并自动识别漫画导入。

### 界面与管理

- 拆分并优化 Windows 桌面 Shell 与书架，增加书架搜索、最近阅读、刷新和更清晰的状态反馈；
- Linux 管理界面可开启、关闭或重启业务服务，操作期间管理通道保持在线；
- 发布范围通过 403 项 Flutter、568 项 Python 和 62 项管理界面测试；正式 Release 已上传 Windows ZIP、Windows 安装 EXE、Android APK 与三份 SHA-256。

## v2.1.0

发布于 2026-09-06，版本号为 `2.1.0+40`。[查看完整更新说明](../releases/v2.1.0.md) · [查看 Release](https://github.com/qingscroll/QingJuan/releases/tag/v2.1.0)

### 漫画翻译工作台

- 统一移动端主题、表面、导入和设置交互，继续阅读、任务状态、浅色/深色模式与无障碍行为更清晰。

## v2.0.0

发布于 2026-08-21，版本号为 `2.0.0+32`。[查看 Release](https://github.com/qingscroll/QingJuan/releases/tag/v2.0.0) · [查看 PR #46](https://github.com/qingscroll/QingJuan/pull/46)

### Linux 多用户

- Linux 后端新增注册、登录和用户会话，每位用户拥有独立的书架、阅读进度、下载与翻译任务；
- 旧版本书籍、进度和任务在首次迁移时自动归属内置 `admin` 用户，不删除数据或模型设置；
- 普通用户可使用全服书源、解析器和翻译服务，只有管理员可修改服务级配置；番茄、起点等登录态按用户隔离，Bika 凭据仍属于全服配置。

### 注册、GitHub 与两步验证

- 自助注册始终要求唯一邮箱；管理员可独立启用邮箱验证码和固定身份牌，两项同时启用时必须全部通过；
- SMTP 支持 STARTTLS、SSL 和无认证本地 Relay，验证码具备有效期、重发间隔、错误次数及来源限流；
- 新增 GitHub OAuth App Device Flow，用户登录本地账号后可自行绑定；GitHub 不会自动注册账号，也不申请邮箱或仓库权限；
- 新增 TOTP 两步验证与 10 个一次性恢复码，密码或 GitHub 登录都必须完成第二因素；账号密码、角色或安全设置变化会立即撤销旧会话。

### 管理与在线升级

- 管理界面新增用户管理、注册设置和后端升级页面；可创建或停用用户、维护资料、重置密码、调整角色并撤销会话；
- 在线升级器只更新受信部署仓库，在独立 release 中完成下载、依赖安装和预检，最终切换时短暂重启，失败时恢复旧版本；
- 客户端识别升级重启并自动等待恢复，连接恢复后再执行模型健康检查。

### 客户端与 Windows 本机模式

- 重构移动端“我的”页面，集中账号状态、书架摘要、服务器连接和常用设置；未登录时不加载其他用户数据；
- 优化窄屏“跟随系统”主题选项、快速音量键翻页、跨章切换和桌面端鼠标滚轮缓动；
- Windows 本机模式继续无需 Linux、连接 Token 或用户账号，注册、GitHub 与 2FA 入口保持隐藏；
- Windows 翻译模型、API 密钥、系统提示词和外部 OCR 在客户端设置中维护，本机后端不启动 `/admin/`。

### 升级与验证

- v2.0.0 可直接覆盖 v1.7.7；数据库迁移自动且幂等。Linux 升级前应配套备份 `/var/lib/qingjuan` 与 `/etc/qingjuan/backend.env`；
- Flutter 格式、Analyzer 与 210 项客户端测试通过；Python Ruff 与 366 项后端测试通过；管理界面 56 项测试与生产构建通过；
- PR 的 Flutter、Python、React 管理界面和 Linux 原生后端四项门禁，以及 Windows x64 与 Android 构建均已成功；标签发布工作流已完成，正式 Release 已上传两个主文件和两份 SHA-256 校验文件。

## v1.7.8

发布于 2026-08-21，版本号为 `1.7.8+29`。[查看 Release](https://github.com/qingscroll/QingJuan/releases/tag/v1.7.8) · [查看 PR #45](https://github.com/qingscroll/QingJuan/pull/45)

### Windows 本机模型设置

- Windows 本机模式改为直接在客户端 **设置 → 翻译服务** 中维护模型、API 密钥、视觉能力、系统提示词和外部 OCR；

### 阅读分页与安全

- 分页阅读按真实字体、文字缩放、行距、标题和页脚高度测量内容，减少页尾截断与溢出；
- 分页优先在换行和中文标点处断开，并改进极端窗口和无障碍文字缩放下的缓存与前进逻辑；
- 设置保存显式使用保留、替换或清除语义，防止空值覆盖既有密钥或客户端回传不应暴露的凭据；
- v1.7.8 可直接覆盖 v1.7.7，不涉及书库、进度或设置迁移；正式发布工作流与四个 Release 资产均已完成。

## v1.7.7

正式版，版本号为 `1.7.7+28`。[查看 Release](https://github.com/qingscroll/QingJuan/releases/tag/v1.7.7) · [查看 PR #42](https://github.com/qingscroll/QingJuan/pull/42)

### 新增四个内置解析器

- 新增刺猬猫阅读、SF 轻小说和少年梦阅读，支持作品信息、完整分卷目录、可取得章节正文与后端搜索；
- 新增 E-Hentai，支持画廊元数据、搜索和可取得原图；一本画廊作为一个漫画章节保存；
- 内置解析器从 22 个增至 26 个，新解析器默认启用，并在现有后端启动时自动补充书源与插件状态记录；
- 当前客户端搜索下拉仍保留书源、夸克、番茄和起点四项；其他解析器可通过作品链接导入。

### 完整目录与章节访问状态

- VIP、订阅、付费、登录和其他访问状态会保留在目录与章节元数据中，不再仅因标记本身提前过滤章节；
- 解析器会请求对应的正常正文端点或 Viewer；上游实际返回可验证完整正文或漫画页面时保存；
- 上游只返回试读、空内容、限制提示或当前不支持的格式时记录明确错误，并继续处理其他章节；
- 不伪造账号、会员、购买状态或上游响应，实际可取得内容仍由站点当前响应、网络、地区和账号状态决定。

### 现有解析器一致性

- 番茄目录访问状态继续保留，网页正文不可用时按既有规则回退 APP 全文接口并校验内容完整性；
- 起点、夸克、Yanmaga、Pixiv Comic 与拷贝漫画改为保留完整目录，再按上游实际返回内容判断章节是否可保存；
- COMICORES 继续只提供作品搜索和元数据，并明确标注当前尚未实现章节资源解析。

### 验证与升级

- `pubspec.yaml` 已更新为 `1.7.7+28`；Python Ruff、244 项 Pytest 和差异格式检查通过；
- PR 的 Flutter、Python、React 与 Linux 四项质量门禁均成功，Android APK 与 Windows x64 正式产物进入构建阶段；
- v1.7.7 可直接升级 v1.7.6，现有书库、阅读进度和设置无需手工迁移。

## v1.7.4

发布于 2026-08-20，版本号为 `1.7.4+25`。[查看 Release](https://github.com/qingscroll/QingJuan/releases/tag/v1.7.4) · [查看 PR #39](https://github.com/qingscroll/QingJuan/pull/39)

### 小说阅读排版

- 小说段落统一使用稳定的两字首行缩进和两端对齐，短段与自动换行长段的首字保持在同一位置；

### Android 系统栏与音量键阅读

- Android 打开阅读器后自动隐藏顶部时间状态栏，同时保留底部导航或手势区；应用内控制层显隐不再改变正文安全区或分页结果；

- 到达章节边界时，同一次按键会等待相邻章节装入并继续移动；从章首向上时可直接定位到上一章末屏。

### Token 输入

- Android 连接 Token 密码框继续保留原生选区，并在字段旁提供明确的“粘贴”按钮，解决部分系统长按菜单无法粘贴的问题；
- 粘贴操作只读取纯文本并写入当前输入框，不记录、回显或上传剪贴板内容。

- `pubspec.yaml`、Android、Windows 与 FastAPI 已统一为 `1.7.4+25`；

### Linux 章节缓存与阅读优先级

- Linux 后端完成按需导入后，会从最早未缓存章节开始顺序缓存全部可访问正文；客户端断开不会取消，服务重启后会根据目录和已落盘文件继续；
- 用户打开章节时，当前章和下一章优先于后台顺序缓存；同章并发请求会合并，不相关的低优先级下载会暂停并重新排队；
- 单章失败只记录该章并继续后续缓存；Windows 本机后端仍保持当前章与相邻章的轻量策略。

### 模型端点与管理安全

- 翻译模型和外部 OCR 设置只允许带 CSRF 的管理会话修改，普通客户端 Token 不能修改设置或触发真实外部探针；
- API 密钥与规范化 Origin 绑定，切换协议、主机或端口后需要重新录入；
- 出站请求默认只允许公网 HTTPS，并拒绝回环、私网、链路本地、保留地址、云元数据、环境代理和自动重定向；
- Linux 局域网自建模型可由运维方通过 `QINGJUAN_MODEL_ENDPOINT_ALLOWLIST` 精确授权，安装脚本会保留已有白名单。

### Android 界面

- 底部导航改为范围受控的悬浮圆角液态玻璃表面，统一亮暗主题的描边、阴影、选中态和触控反馈；
- 透明效果关闭或背景不适合采样时自动提高表面不透明度，并限制模糊区域以控制滚动渲染成本。

### 发布与升级

- 固定 Flutter 3.24.3 下通过 Dart 格式、Analyzer、132 项 Flutter 测试与 Android Release APK 构建；Python Ruff、Compileall、232 项 Pytest，以及管理端类型检查、25 项测试和生产构建通过；
