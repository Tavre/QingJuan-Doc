# 任务与导出

下载、翻译和部分导入操作由当前后端作为后台任务执行。Linux 远程任务在关闭客户端后继续运行；Windows 本机模式退出时会回收当前客户端启动的本机后端进程。

## 任务状态

| 状态 | 含义 |
| --- | --- |
| `queued` | 已进入队列，等待并发名额 |
| `running` | 正在处理，可持续更新完成数和进度 |
| `pause_requested` / `paused` | 正在安全暂停，或已暂停并可继续 |
| `cancel_requested` / `cancelled` | 正在安全取消，或已取消 |
| `completed` | 所有计划步骤已完成 |
| `failed` | 任务失败，保留脱敏原因和可重试信息 |

任务中心可按分类查看下载与翻译，并显示用户可读说明、更新时间和日志。漫画翻译会逐页写入断点，失败或服务重启后可跳过仍然有效的已完成页面。

v2.1.0 的 Windows 漫画翻译工作台还会逐文件显示状态，并允许停止批处理。停止后已完成文件和工程目录仍然保留；书架来源任务只有在整章页面完整时才发布译文，单页失败不会覆盖为缺页章节。

删除作品时，相关任务会安全停止或失效。单个任务异常不应终止整个后端进程。

v2.3.0 可对支持的任务执行暂停、继续和取消。暂停会等待当前安全写入点，不会强制中断正在发布的章节；Linux 多用户队列按账号轮转，避免单个账号的长队列持续占用全部处理机会。

## 导出小说

已下载的小说章节支持：

- `TXT` / `TEXT`；
- `DOCX`；
- `EPUB`。

可以导出单章、所选章节或全部已下载章节。多章会按目录顺序合并；存在有效译文时优先导出译文，否则使用原文。

## 导出漫画

漫画支持：

- 在 Windows 漫画翻译工作台中导出译文、导出原文或选择独立输出目录；
- 多页 `PDF`；
- 图片 ZIP，按作品和章节建立目录并使用稳定序号命名。

已生成且仍有效的译图会优先导出。旧缓存或校验失效的译图不会与新结果混用。

## 保存文件

后端先在受控导出目录生成有时效的产物，再由客户端流式下载。远程模式使用认证 URL；本机模式不需要连接 Token。Windows 和 Android 使用系统文件选择器确定最终保存位置，后端不接受客户端文件路径。

下载完成前不要关闭文件选择器或撤销目标目录权限。过期产物会由服务端清理，需要时可以重新导出。

作品详情的 **空间占用** 会统计原文、译文、图片和导出文件。当前只允许在预览清单并再次确认后清理可重新生成的导出文件；正文、图片、译文、笔记和阅读进度不会被该操作删除。

## 任务一直不动

1. 查看任务的当前消息和最后更新时间；
2. 确认当前后端仍在运行；
3. 本机模式查看任务中心的脱敏信息；远程模式由管理员在管理界面或使用 `sudo journalctl -u qingjuan-backend -f` 查看对应阶段；
4. 检查第三方站点或翻译服务是否返回限速、超时或鉴权错误；
5. 先降低并发，再重试失败任务。

不要把正文、Token、Cookie 或 API 密钥复制到公开排障信息中。
