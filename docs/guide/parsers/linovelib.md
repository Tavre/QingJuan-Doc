# Linovelib / Bilinovel 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `linovelib` |
| 版本 | `1.0.0` |
| 匹配域名 | `linovelib.com`、`bilinovel.com` |
| 作品类型 | 轻小说 |
| 默认状态 | 启用 |

## 支持能力

该解析器读取 Linovelib 与 Bilinovel 的作品目录、分卷结构和带插图章节。当前没有内置搜索能力，请粘贴任一支持域名下的作品页面链接导入。

两个域名共用同一插件开关。停用 `linovelib` 会同时停止这两个域名的新预览和章节请求。
