# Syosetu 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `syosetu` |
| 版本 | `1.0.0` |
| 匹配域名 | `syosetu.com`，不含 `novel18.syosetu.com` |
| 作品类型 | 长小说 |
| 默认状态 | 启用 |

## 支持能力

Syosetu 解析器读取小説家になろう系列的公开作品目录与章节。当前没有内置搜索能力，请粘贴作品页面链接导入。

`novel18.syosetu.com` 由独立的 [Novel18 解析器](./novel18.md) 处理，以保持年龄限制站点的边界清晰。
