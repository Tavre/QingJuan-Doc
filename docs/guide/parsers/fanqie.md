| 属性 | 内容 |
| --- | --- |
| 插件 ID | `fanqie` |
| 版本 | `1.1.0` |
| 匹配域名 | `fanqienovel.com` |
| 作品类型 | 长小说 |
| 默认状态 | 启用 |

## 支持能力

番茄解析器支持作品预览、目录、章节正文、站内搜索和“边看边下”。它还支持扫码登录、Cookie 登录兜底，以及一键添加当前账号书架。

## 使用方式

- 在青卷 **搜索** 中查找番茄作品，或粘贴作品页面链接；
- 导入时可选择按需下载或全部下载；
- 需要同步账号书架时，在 **插件配置** 或 `/admin/#plugins` 中扫码登录，再选择 **添加账号书架**；
- 当前网络无法取得二维码时，可从已登录网页请求中复制完整 Cookie 请求头完成登录。

账号书架会跨分页去重、跳过当前后端已有作品，并显示新增、跳过和失败统计。Cookie 和登录会话只保存在当前后端进程内存中，重启后需要重新登录。

## v1.7.3 正文稳定性

番茄阅读页返回 HTTP 200 但正文为空、显示验证页或缺少 `__INITIAL_STATE__` 时，青卷会按既有上限退避重试，不再把无正文页面当作成功。网页 SSR 正文仍不可用时，会继续使用番茄 APP 全文回退链。

## v1.7.7 访问标记

目录中的锁定、付费等字段会保留为访问状态，不再仅因标记本身提前跳过章节。网页或 APP 正常接口实际返回可验证完整正文时会保存；两条路径都只返回试读、限制提示或空内容时会明确报错。账号 Cookie 仍只用于登录状态和账号书架同步，不参与章节请求。

解析器不会伪造账号、购买状态或上游响应。
