# 起点中文网解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `qidian` |
| 版本 | `1.0.0` |
| 匹配域名 | `qidian.com` |
| 作品类型 | 长小说、轻小说 |
| 默认状态 | 启用 |

## 支持能力

起点解析器支持匿名搜索、作品预览、完整目录、可取得的章节正文、“边看边下”、扫码登录和一键添加当前账号书架。可在搜索页选择 **起点**，也可粘贴作品链接或从账号书架导入。

## 账号书架

1. 在 **插件配置** 或 `/admin/#plugins` 中启用起点；
2. 选择 **扫码登录**，使用起点官方 App 扫码并确认；
3. 登录成功后选择 **添加账号书架**；
4. 等待任务读取全部分组和分页，并查看新增、跳过与失败统计。

起点不提供 Cookie 登录入口。登录 Cookie、会话和账号标识只保存在当前后端进程内存中，后端重启后需要重新登录。

## v1.7.7 访问标记

VIP、订阅或购买状态会保留在目录元数据中，但不会仅因标记本身提前删除章节。上游返回普通可解析正文时会保存；只返回试读、空内容或当前尚未支持的加密正文格式时会明确报错。扫码登录仍只服务于账号书架同步，解析器不会伪造设备、账号或购买状态。
