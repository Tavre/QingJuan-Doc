# 刺猬猫阅读解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `ciweimao` |
| 版本 | `1.0.0` |
| 匹配域名 | `ciweimao.com` |
| 作品类型 | 轻小说 |
| 默认状态 | 启用 |

## 支持能力

刺猬猫解析器支持作品信息、分卷目录、章节正文和站内搜索。可粘贴 `https://www.ciweimao.com/book/{作品 ID}` 形式的作品链接导入；解析器本身具备搜索能力，但当前客户端搜索下拉没有单独的“刺猬猫”入口。

目录会保留 VIP、锁定或付费等访问状态。青卷会使用站点正常下发的章节访问参数解析响应：上游实际返回可验证正文时保存；要求登录、订阅或没有返回正文时显示明确错误。当前不提供刺猬猫账号登录、Cookie 导入或账号书架同步。

停用 `ciweimao` 后，新的搜索、作品预览和章节请求会在访问站点前被拒绝；已经缓存的章节仍可阅读。
