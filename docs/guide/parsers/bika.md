# Bika Web App 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `bika` |
| 版本 | `1.0.0` |
| 匹配域名 | `bikawebapp.com` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

Bika 解析器支持作品预览、章节、漫画图片和内置作品搜索。使用前需要在当前后端配置有效的 Bika 站点账号凭据；凭据是否可用取决于站点当前接口和账号状态。

凭据属于当前后端设置，不会因 Windows 本机与 Linux 远程模式切换而自动同步。不要把账号或密码写入 Issue、日志、书源 JSON 或文档截图。

仅限满足站点年龄要求、所在地区法律允许且有权访问内容的用户启用。
