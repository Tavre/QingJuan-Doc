# COMICORES 漫核解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `comicores` |
| 版本 | `1.0.0` |
| 匹配域名 | `comicores.cc` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

COMICORES 解析器只提供公开作品搜索和元数据预览，例如标题、作者、封面与简介。当前不提供章节目录或漫画图片读取，也没有账号登录和书架导入。

站点登录后可见的网盘、付费下载或其他受限资源不在支持范围内，青卷不会解析或下载这些资源，也不会把元数据结果伪造成可阅读章节。主搜索页当前没有单独的 COMICORES 引擎入口。

停用 `comicores` 后，后端会在网络请求前拒绝新的搜索和预览请求。
