# COMICORES 漫核解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `comicores` |
| 版本 | `1.0.0` |
| 匹配域名 | `comicores.cc` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

COMICORES 解析器提供作品搜索和元数据预览，例如标题、作者、封面与简介。当前尚未实现章节资源解析，也没有账号登录和书架导入。

当前解析器不会把元数据、简介、网盘或下载入口伪造成可阅读章节。后续如实现章节解析，也必须遵循统一的“上游实际返回且内容可验证才保存”规则。主搜索页当前没有单独的 COMICORES 引擎入口。

停用 `comicores` 后，后端会在网络请求前拒绝新的搜索和预览请求。
