| 属性 | 内容 |
| --- | --- |
| 插件 ID | `shaoniandream` |
| 版本 | `1.0.0` |
| 匹配域名 | `shaoniandream.com` |
| 作品类型 | 长小说 |
| 默认状态 | 启用 |

## 支持能力

少年梦解析器支持作品信息、分卷目录、章节正文和站内搜索。可粘贴 `https://www.shaoniandream.com/book_detail/{作品 ID}` 形式的作品链接导入；解析器具备搜索能力，但当前客户端搜索下拉没有单独的“少年梦”入口。

目录会保留免费或受限状态。青卷会使用站点正常返回的章节访问参数解析正文：上游实际提供可验证内容时保存；要求登录、订阅、缺少解密参数或没有正文时显示明确错误。当前不提供少年梦账号登录、Cookie 导入或账号书架同步。

停用 `shaoniandream` 后，新的搜索、作品预览和章节请求会在访问站点前被拒绝；已经缓存的章节仍可阅读。
