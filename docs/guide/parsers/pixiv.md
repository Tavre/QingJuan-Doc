# Pixiv 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `pixiv` |
| 版本 | `1.0.0` |
| 匹配域名 | `pixiv.net`，不含 `comic.pixiv.net` |
| 作品类型 | 长小说、漫画 |
| 默认状态 | 启用 |

## 支持能力

Pixiv 解析器支持小说、小说系列和多页插画作品的预览与章节内容。当前没有内置搜索能力，请粘贴对应作品或系列链接导入。

`comic.pixiv.net` 由独立的 [Pixiv Comic 解析器](./pixiv-comic.md) 处理。需要登录、年龄确认或已限制访问的作品不会被绕过限制。
