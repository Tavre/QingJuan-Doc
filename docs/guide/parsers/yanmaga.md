| 属性 | 内容 |
| --- | --- |
| 插件 ID | `yanmaga` |
| 版本 | `1.0.0` |
| 匹配域名 | `yanmaga.jp` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

Yanmaga 解析器读取作品信息与完整目录，并在官方 Viewer 返回可解析内容时复原漫画页面。当前没有内置搜索能力，请粘贴作品或章节链接导入。

目录中的注册、登录、点数和单次免费等状态会保留为元数据，不再提前删除章节。青卷会逐章请求同作品、同章节的官方 Viewer：返回完整页面列表时保存；没有返回内容标识或页面列表时明确报错。解析器不会伪造登录、点数或购买状态。
