# Pixiv Comic 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `pixiv-comic` |
| 版本 | `1.0.0` |
| 匹配域名 | `comic.pixiv.net` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

Pixiv Comic 解析器读取作品信息、完整目录和官方页面实际下发的漫画图片。当前没有内置搜索能力，请粘贴作品或章节页面链接导入。

目录中的访问状态只作为元数据保留。阅读接口实际返回可验证图片时会按页面下发的网格参数复原；没有返回图片、要求登录或购买时明确报错。青卷不会伪造登录或购买状态。
