# SF 轻小说解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `sfacg` |
| 版本 | `1.0.0` |
| 匹配域名 | `sfacg.com` |
| 作品类型 | 轻小说 |
| 默认状态 | 启用 |

## 支持能力

SF 轻小说解析器支持菠萝包 / SF 轻小说的作品信息、完整分卷目录、章节正文和站内搜索。可粘贴 `https://book.sfacg.com/Novel/{作品 ID}/` 形式的作品链接导入；解析器具备搜索能力，但当前客户端搜索下拉没有单独的“SF 轻小说”入口。

VIP 或火券等访问状态只作为目录元数据保留。上游接口返回普通可解析正文时会保存；如果接口要求登录和对应访问权限，或没有返回正文，青卷会给出明确错误。当前不提供 SF 账号登录、Cookie 导入或账号书架同步。

停用 `sfacg` 后，新的搜索、作品预览和章节请求会在访问站点前被拒绝；已经缓存的章节仍可阅读。
