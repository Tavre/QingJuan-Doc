## 支持能力

夸克小说解析器通过书旗网页内核提供搜索、作品信息、完整目录和章节正文解析，并支持“边看边下”。在搜索页选择 **夸克** 后，可按书名或作者查找作品并加入书架。

目录中的免费、VIP 或付费状态只作为元数据保留。章节正文端点实际返回完整内容时会保存；返回空内容、试读或限制提示时会明确报错，不会用试读片段伪装完整章节。解析器不接入登录 Cookie、账号书架，也不会伪造购买状态。

停用 `quark` 后，后端会在网络请求前拒绝新的夸克搜索、预览与章节抓取；已经缓存的章节不受影响。

## v1.7.1 稳定性改进

- 目录请求遇到限流或 HTTP 502 / 503 / 504 临时网关错误时会进行有界重试；
- 同一作品的完整目录会短时缓存在当前后端进程内，并合并并发请求，供预览、导入和首次按需阅读复用；
- Android 从搜索结果加入书架使用后台任务，不再同步等待长目录请求；
- HTML 错误页不会原样显示给用户，公开错误只保留阶段和 HTTP 状态。

缓存不包含账号状态，也不会改变上游实际返回的章节内容。

## v1.7.7 完整目录

目录不再按免费标记预先过滤。按需导入会保存完整目录，再逐章尝试正常正文端点；取得并验证完整正文时缓存，无法取得时记录该章错误并继续处理后续章节。
