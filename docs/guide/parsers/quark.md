# 夸克小说解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `quark` |
| 版本 | `1.0.0` |
| 匹配域名 | `shuqi.com`、`novel.quark.cn` |
| 作品类型 | 长小说 |
| 默认状态 | 启用 |

## 支持能力

夸克小说解析器通过书旗网页内核提供匿名公开搜索、作品信息、目录和免费章节解析，并支持“边看边下”。在搜索页选择 **夸克** 后，可按书名或作者查找作品并加入书架。

解析器只保存明确标记为免费且返回完整正文的章节，不接入付费章节、登录 Cookie、账号书架，也不会用试读片段伪装完整章节。

停用 `quark` 后，后端会在网络请求前拒绝新的夸克搜索、预览与章节抓取；已经缓存的章节不受影响。
