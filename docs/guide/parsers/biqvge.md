| 属性 | 内容 |
| --- | --- |
| 插件 ID | `biqvge` |
| 匹配域名 | `txt80.net`、`b520.cc`、`blqukan.cc` |
| 作品类型 | 长小说 |
| 默认状态 | 启用 |

## 支持能力

v2.2.0 新增笔趣阁聚合解析器，支持作品搜索、作品与目录预览、章节正文及按需下载。主搜索页可直接选择 **笔趣阁**。

搜索会优先使用八零小说网的动态搜索入口，并聚合笔趣阁 5200 与笔趣看的公开目录索引。后端会处理不同站点的 URL 结构与页面编码，短时缓存搜索和目录结果；单个镜像失败时会暂时冷却并继续使用其他可用来源。

搜索结果会保留实际来源。作品加入书架后，后续章节仍从对应站点获取，不会在镜像之间混用章节或静默替换内容。站点结构、镜像域名或公开策略变化时可能暂时不可用。
