# Kakuyomu 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `kakuyomu` |
| 版本 | `1.0.0` |
| 匹配域名 | `kakuyomu.jp` |
| 作品类型 | 轻小说、长小说 |
| 默认状态 | 启用 |

## 支持能力

Kakuyomu 解析器支持作品预览、目录、章节正文和内置作品搜索。可直接在青卷 **搜索** 中输入关键词，也可粘贴 Kakuyomu 作品链接导入。

仅处理站点当前公开并可从后端网络访问的内容。遇到目录缺失或章节失败时，先在浏览器确认同一链接仍可访问，再检查插件是否启用。
