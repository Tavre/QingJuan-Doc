# 通用网页解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `generic-web` |
| 版本 | `1.0.0` |
| 匹配范围 | 任意有效的 HTTP / HTTPS 地址 |
| 作品类型 | 长小说、轻小说、漫画 |
| 默认状态 | 启用 |

## 支持能力

通用网页解析器为没有专用模块的作品链接提供基础目录与正文解析。它在所有专用站点解析器之后匹配，因此已支持域名会优先使用对应的专用解析器。

通用回退不保证兼容任意网站，也不提供内置搜索、账号登录或书架导入。复杂脚本渲染、登录、购买、验证码或特殊图片协议通常需要专用解析器。

如果通用解析结果不完整，请不要反复高并发重试；可提交脱敏后的站点域名、作品链接类型和错误阶段到 GitHub Issues，但不要上传正文、Cookie 或付费页面存档。
