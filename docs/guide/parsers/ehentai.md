# E-Hentai 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `ehentai` |
| 版本 | `1.0.0` |
| 匹配域名 | `e-hentai.org`、`exhentai.org` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

E-Hentai 解析器支持画廊搜索、元数据预览和可取得原图的顺序读取。导入 `/g/{gid}/{token}/` 形式的画廊链接后，一本画廊会作为一个漫画章节保存，并保留页面顺序。解析器具备搜索能力，但当前客户端搜索下拉没有单独的“E-Hentai”入口。

青卷只处理当前网络与站点响应实际提供的画廊信息和 HTTPS 原图，不提供站点登录、Cookie 导入或访问限制绕过。画廊已删除、需要登录、地区不可用或没有返回原图时会显示明确错误。

::: warning 年龄与内容边界
该站点可能包含成人内容。请确认自己达到所在地法定年龄，并遵守站点条款、版权要求和所在地法律，只导入你有权访问的内容。
:::

停用 `ehentai` 后，新的搜索、画廊预览和图片请求会在访问站点前被拒绝；已经缓存的漫画页仍可阅读。
