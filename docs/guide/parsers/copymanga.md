# CopyManga 解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `copymanga` |
| 版本 | `1.0.0` |
| 匹配域名 | `copymanga.com`、`copymanga.site` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

CopyManga 解析器使用通用漫画阅读页适配器读取公开作品目录、章节和图片。当前没有内置搜索能力，请粘贴任一支持域名下的作品页面链接导入。

两个域名共用同一插件开关。停用 `copymanga` 会同时停止这两个域名的新预览与章节请求。
