# 拷贝漫画解析器

| 属性 | 内容 |
| --- | --- |
| 插件 ID | `copymanga` |
| 版本 | `1.0.0` |
| 匹配域名 | `mangacopy.com`、`copymanga.com`、`copymanga.site` |
| 作品类型 | 漫画 |
| 默认状态 | 启用 |

## 支持能力

拷贝漫画解析器通过公开接口读取作品搜索结果、详情、分组目录、章节和漫画图片，并支持“边看边下”。它不接入账号登录、Cookie 或账号书架。

三个域名共用同一插件开关。停用 `copymanga` 会在网络请求前停止这些域名的新搜索、预览与章节请求。主搜索页当前没有单独的“拷贝漫画”引擎入口，仍可使用作品链接导入。
