# 书架与导入

书架由当前选中的后端保存。Windows 本机模式使用当前电脑的本机书库；Windows 和 Android 连接同一 Linux 服务时，会看到相同作品、章节状态和阅读进度。

## 从本地文件导入

在 **我的书架** 中选择导入，并通过系统文件选择器选取文件。当前支持：

| 类型 | 用途 | 当前限制 |
| --- | --- | --- |
| `TXT` / `TEXT` | 小说文本 | 最大 64 MB |
| `DOCX` | Word 小说文档 | 最大 256 MB；不支持旧版 `.doc` |
| `EPUB` | 电子书 | 最大 256 MB |
| `PDF` | 漫画或图像文档 | 最大 1 GB、5000 页 |

DOCX 与 EPUB 会检查 ZIP 容器结构、条目数量、解压后总大小和路径安全。PDF 会逐页渲染为本地图片，并作为一个漫画作品导入。

::: tip 旧版 Word 文件
`.doc` 是旧式二进制格式，请先使用 Word 或 LibreOffice 转换为 `.docx`。
:::

## 从站点导入

可在 **搜索** 中从启用的内置或自定义书源查找作品。选择结果后，青卷将作品元数据、封面和章节目录保存到服务端，并按来源能力创建下载。

番茄小说支持两种策略：

- **按需下载**：先导入目录，打开章节时缓存当前章，并在后台顺序预取后续章节；
- **全部下载**：创建任务逐章下载正文，适合明确需要离线保存的作品。

长篇作品全部下载可能耗时较久。任务失败不会把错误提示写成章节正文，可在任务中心查看原因后重试。

## 章节和作品状态

书架会区分作品类型、语言、章节数量与当前任务状态。删除作品前请确认：删除当前后端中的作品会影响所有连接到该后端的客户端。

阅读偏好通常保存在设备本地，书籍内容和阅读进度以当前后端为准。本机与 Linux 书库不会自动同步。

## 导入失败时

1. 确认文件后缀与真实格式一致；
2. 确认文件大小和 PDF 页数未超过限制；
3. 查看 **任务中心** 的脱敏错误与日志；
4. 对站点导入，确认目标作品仍可从当前网络合法访问；
5. Windows 本机模式查看管理界面的脱敏日志；Linux 远程模式可在服务器查看 `journalctl -u qingjuan-backend -f`。不要公开其中的敏感信息。
