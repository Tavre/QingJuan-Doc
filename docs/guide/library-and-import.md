# 书架与导入

书架由当前选中的后端保存。Windows 本机模式使用当前电脑的本机书库；v2.2.0 的 Android 扫描 PC 二维码后可直接使用这份书库。Windows 和 Android 连接同一 Linux 服务并登录同一个用户账号时，也会看到相同作品、章节状态和阅读进度；不同 Linux 用户的数据相互隔离。

## 整理书库

v2.3.0 支持为作品设置分组、标签、置顶和未读／在读／已完成／搁置状态，也可以覆盖书名、作者和简介。关键词会同时匹配作品信息与标签，筛选条件可组合使用，置顶作品始终优先显示。Windows 可从书库卡片或详情页编辑，Android 可长按作品后进入编辑。

## 从本地文件导入

在 **我的书架** 中选择导入，并通过系统文件选择器选取文件。当前支持：

| 类型 | 用途 | 当前限制 |
| --- | --- | --- |
| `TXT` / `TEXT` | 小说文本 | 最大 64 MB |
| `DOCX` | Word 小说文档 | 最大 256 MB；不支持旧版 `.doc` |
| `EPUB` | 电子书 | 最大 256 MB |
| `PDF` | 漫画或图像文档 | 最大 1 GB、5000 页 |

DOCX 与 EPUB 会检查 ZIP 容器结构、条目数量、解压后总大小和路径安全。PDF 会逐页渲染为本地图片，并作为一个漫画作品导入。

::: tip 旧版 Word 文件
`.doc` 是旧式二进制格式，请先使用 Word 或 LibreOffice 转换为 `.docx`。
:::

## 从站点导入

**推荐**页可按站点浏览推荐栏目与排行榜，分页查看作品，并先预览作品信息和目录再加入书架。搜索与推荐共用实际来源，不会把推荐结果伪装成青卷自有内容。

可在 **搜索** 中选择导入插件、书源、夸克、番茄、起点或笔趣阁查找作品，也可通过受支持的作品链接导入。选择结果后，青卷将作品元数据、封面和可用目录保存到服务端，并按来源能力创建下载。切换搜索引擎会清空旧结果，结果中的实际来源会被保留。

v2.2.0 增加 **导入插件** 与 **笔趣阁** 搜索引擎，并允许在添加书籍时直接填写 18Comic 的纯数字禁漫本子号。桌面和 Android 都会自动识别本子号、锁定漫画类型并使用完整下载；请填写专辑编号而不是章节编号。

番茄小说支持两种策略：

- **按需下载**：先导入目录。Windows 本机后端保持当前章与相邻章的轻量缓存；Linux 远程后端从 v1.7.2 起会在后台顺序处理目录章节，同时优先处理正在阅读的当前章和下一章；v1.7.7 会尝试完整目录中的全部章节，单章无法取得时记录失败并继续；
- **全部下载**：创建任务逐章下载正文，适合明确需要离线保存的作品。

长篇作品全部下载可能耗时较久。任务失败不会把错误提示写成章节正文，可在任务中心查看原因后重试。

Linux 的后台章节缓存不依赖客户端持续在线，服务重启后会根据目录和已落盘文件继续。单章失败不会阻止后续章节；升级后请为按需导入作品预留足够磁盘空间。用户主动打开尚未缓存的章节时，该章和下一章会越过顺序队列优先准备。

v1.7.7 不再仅按免费、VIP、订阅或付费标记提前过滤目录。上游实际返回可验证完整正文或漫画页面时保存；只返回试读、空内容、限制提示或当前不支持的格式时记录错误。新增刺猬猫、SF 轻小说、少年梦和 E-Hentai 作品链接导入；COMICORES 当前仍只有元数据预览，没有可导入章节。

v1.7.1 中，Android 从夸克、番茄或起点搜索结果加入书架时改用后台链接任务，按钮会在处理期间锁定并显示进度，随后轮询完成、失败、取消或超时状态。Windows 保持原有导入交互。夸克目录会短时复用，以减少预览、导入和首次阅读连续请求导致的限流。

v2.3.0 支持一次提交多个作品链接，并在 **导入历史** 中查看已排队、运行、暂停、失败或完成的记录。未完成任务和进度会持久保存，后端重启后可继续恢复；重复链接会按当前书库和历史记录去重。

## 从账号书架导入

v1.6.0 支持把当前登录的番茄小说或起点中文网账号书架一键添加到青卷：

1. Windows 本机模式打开 **插件配置**；Linux 远程模式打开 `/admin/#plugins`；
2. 启用番茄或起点插件并完成扫码登录；番茄也可在扫码不可用时使用 Cookie 登录；
3. 选择 **添加账号书架**，等待任务完成；
4. 查看新增、跳过和失败数量，单本失败可按提示单独处理。

导入会跨站点分组和分页去重，跳过当前用户书架已有作品，并以“边看边下”模式添加新的文字作品。Linux 中的番茄、起点等登录状态按青卷用户隔离，并且只存在后端进程内存中；后端重启后需要重新登录。详细步骤见[书源、插件与搜索](./sources-and-search.md#番茄与起点账号书架)。

## 章节和作品状态

### 连载追更

连载作品可从书库卡片、Android 长按工具栏或作品详情打开 **连载追更**。青卷会根据来源元数据判断连载状态，支持手动检查、1～168 小时的定时检查、未读新章提示和自动下载。检查只追加新章节，不改动旧目录顺序、标题、译文或阅读位置；来源无法可靠判断时会显示“不支持”或“状态未知”，不会猜测完结状态。

### 将书架漫画送入翻译工作台

v2.1.0 的 Windows 客户端可在漫画作品详情中点击 **漫画翻译**：没有勾选章节时导入全书，勾选后仅导入所选章节。也可以从侧栏打开漫画翻译工作台，再通过 **从书架选择** 选择漫画和章节。

书架原图会缓存到按后端与用户隔离的本地目录；重复导入不会删除已经存在的翻译工程。整章成功后，译图与区域元数据会作为该章节的 **译文** 写回书架；单页失败不会生成残缺章节。具体编辑和重新渲染方式见[翻译](./translation.md#windows-漫画翻译工作台)。

书架会区分作品类型、语言、章节数量与当前任务状态。删除作品前请确认：Windows 本机模式会删除本机作品；Linux 远程模式只删除当前用户书架中的作品，并影响该账号已登录的全部设备。

阅读偏好通常保存在设备本地，书籍内容和阅读进度以当前后端为准。本机与 Linux 书库不会自动同步。

## 导入失败时

1. 确认文件后缀与真实格式一致；
2. 确认文件大小和 PDF 页数未超过限制；
3. 查看 **任务中心** 的脱敏错误与日志；
4. 对站点导入，确认目标作品仍可从当前网络合法访问；
5. Windows 本机模式先查看任务中心的脱敏信息；Linux 远程模式可由管理员在管理界面或服务器查看 `journalctl -u qingjuan-backend -f`。不要公开其中的敏感信息。
