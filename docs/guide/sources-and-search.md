# 书源、插件与搜索

青卷使用两类能力发现作品和章节：**站点解析插件**，以及用户导入的 **Legado / 阅读 App 书源规则**。站点插件又分为随程序发布的内置插件和 v2.2.0 起可导入的独立插件包；它们都保存在当前后端中，但与 Legado 书源的管理入口和数据模型相互独立。

## 内置站点解析插件

青卷公开内置解析器的名称、稳定 ID、版本、匹配域名、作品类型、能力、标签和启停状态：

- 小说与插画：番茄小说、起点中文网、夸克小说、刺猬猫阅读、SF 轻小说、少年梦阅读、Kakuyomu、Syosetu、Novel18、Hameln、Novelup、Alphapolis、Linovelib / Bilinovel、Pixiv；
- 漫画：18Comic、Bika Web App、E-Hentai、Pixiv Comic、Yanmaga、Webtoons、Mangabz、漫画柜、拷贝漫画、COMICORES 漫核、动漫之家；
- 回退：通用网页解析器。

每个解析器的域名、能力和注意事项见[解析器总览](./parsers/)。网站结构、登录要求和地区策略可能变化；“内置支持”不表示每个作品在任何网络环境中都能永久下载。

## 推荐与排行榜

v2.3.0 的 **推荐** 入口按真实站点展示公开推荐栏目和排行榜，可分页浏览并在导入前预览作品。目前覆盖番茄、起点、刺猬猫、笔趣阁聚合、SF 轻小说、少年梦、夸克、Kakuyomu、哔哩哔哩漫画、18Comic、拷贝漫画、COMICORES、E-Hentai、Yanmaga 与 YY 漫画；对应解析器停用时，该站点也会从推荐列表停用。

推荐内容来自第三方站点，青卷只做来源标注、短时缓存和分页展示，不生成推荐排序，也不会绕过站点登录、地区或访问限制。

### 在哪里管理插件

| 使用方式 | 管理入口 | 影响范围 |
| --- | --- | --- |
| Windows 本机后端 | Windows 左侧导航中的 **插件配置** | 只影响当前本机后端 |
| Windows Linux 远程模式 | Linux 管理界面的 **插件管理** | 影响连接该服务的全部客户端 |
| Android 连接 PC | 不显示代码安装入口 | 使用 PC 本机后端已经安装和启用的插件 |
| Android 连接 Linux | 不显示代码安装入口 | 由所连接 Linux 服务的管理员统一维护 |

插件页支持按名称或域名搜索、按启停状态筛选，并按小说、漫画和通用回退分组。内置插件只允许 **启用 / 停用**；导入插件可以更新或卸载。

停用插件后，后端会在发出新的第三方请求前拒绝对应预览、搜索和章节抓取；已经缓存到当前书库的章节仍可阅读。

## 导入站点插件包

v2.2.0 支持 `.qjplugin` 或 `.zip` 站点插件包：

1. Windows 本机模式打开 **插件配置 → 导入插件**；Linux 管理员打开 `/admin/#plugins → 导入插件`；
2. 选择文件后先核对名称、稳定 ID、作者声明、版本、域名、作品类型和能力；预检阶段不会执行插件代码；
3. 确认来源可信后勾选风险确认并安装；安装成功后立即参与作品链接匹配；
4. 更新时导入相同 ID 的更高版本；v2.3.0 可运行包完整性与兼容性自检，并显式回退到保留的上一版本；
5. 卸载只删除插件包，已经加入书架和缓存的章节继续保留。有活跃解析调用或任务时，维护操作会被拒绝。

导入插件可提供作品预览、章节、搜索和按需下载。支持搜索的插件会出现在搜索页的 **导入插件** 引擎中；Android 可以使用当前后端已经安装的插件，但不能从手机上传 Python 代码。

::: danger 插件不是沙箱
插件是直接运行在当前后端进程中的 Python 代码，能够访问该进程拥有的文件、网络和环境。作者字段只是自我声明，SHA-256 只用于确认包内容一致，二者都不能证明代码安全。只安装来源可信且经过审查的插件。完整格式、网络限制和开发示例见[站点插件规范](../development/07-site-plugin-spec.md)。
:::

## 选择搜索引擎

v2.2.0 搜索页提供以下引擎：

| 引擎 | 用途 |
| --- | --- |
| 导入插件 | 同时查询当前后端已安装、已启用且声明搜索能力的站点插件 |
| 书源 | 同时查询当前后端已启用且兼容搜索的 Legado / 阅读 App 书源 |
| 夸克 | 查询夸克小说的书旗网页内核，保留完整目录并解析上游实际返回的完整正文 |
| 番茄 | 使用番茄小说匿名公开搜索，不要求先登录账号 |
| 起点 | 使用起点移动站公开搜索，不要求先登录账号 |
| 笔趣阁 | 优先使用八零小说网搜索，并聚合笔趣阁 5200、笔趣看等可用镜像目录 |

切换引擎会清空上一引擎的结果，避免混淆来源；每条结果仍会保留实际来源，加入书架时继续使用现有的作品链接导入流程。笔趣阁引擎会短时缓存搜索与目录结果，并在单个镜像失败后暂时冷却，避免连续重复请求不可用站点。

### v1.7.1 夸克导入稳定性

Android 从夸克搜索结果加入书架时，会创建后台链接任务并轮询结果。界面会显示正在加入，并正确处理任务完成、失败、取消和等待超时；超时不表示任务已经被后端取消，仍可返回书架页查看进度。

后端会对夸克限流以及 HTTP 502 / 503 / 504 临时网关错误做有限次数重试，并短时复用同一作品的完整目录。若上游返回 HTML 错误页，客户端只显示可操作的 HTTP 错误，不会展示整页 HTML。v1.7.7 起不再按免费标记预先过滤目录，具体规则见下节。

### v1.7.7 新解析器与章节状态

- 新增刺猬猫阅读、SF 轻小说、少年梦阅读和 E-Hentai，共 26 个内置解析器；
- 新解析器都声明后端搜索能力，但当前客户端搜索下拉仍只单列书源、夸克、番茄和起点；可直接粘贴受支持的作品或画廊链接导入；
- VIP、订阅、付费、登录等目录状态会保留为元数据，不再单独导致章节被删除；
- 上游实际返回可验证完整正文或漫画页面时保存；只返回试读、空内容、限制提示或当前不支持的格式时记录明确错误并继续其他章节；
- 解析器不会伪造账号、购买状态或上游响应。

## 番茄与起点账号书架

番茄小说和起点中文网支持账号登录与一键添加当前账号书架：

1. 先在 **插件配置** 或 `/admin/#plugins` 中启用对应插件；
2. 选择 **扫码登录**，使用站点官方 App 扫码并在手机上确认；
3. 番茄二维码在当前网络不可用时，可改用 **Cookie 登录**；起点只提供扫码登录；
4. 登录成功后选择 **添加账号书架**，在任务面板查看读取、去重、跳过、成功和失败数量。

导入会跨分组和分页去重，自动跳过当前用户书架中已有的作品，并以“边看边下”模式添加新的文字作品。单本失败不会撤销已经成功添加的作品，同一插件同一时间只运行一个书架导入任务。

::: warning 登录凭据
站点 Cookie、会话与账号标识只保存在当前后端进程内存中，不写入数据库、普通日志、浏览器存储或客户端设置。Linux 中番茄、起点等登录态按青卷用户隔离；Bika 凭据仍是管理员维护的全服配置。后端重启后需要重新登录。不要在 Issue、截图或聊天中发送 Cookie。
:::

## 少年梦账号登录

v2.2.0 将少年梦解析器升级到 `1.1.0`。在 **插件配置** 中选择账号登录后，青卷会打开受控登录页面；在页面中填写少年梦账号密码并完成人机验证。成功后，解析器可以请求该账号当前正常可访问的章节。

少年梦登录状态按当前青卷用户隔离，只保存在后端进程内存中，退出登录或后端重启后清除。客户端、普通日志和数据库不会保存明文密码；登录失败也不会回显上游响应或凭据。

## 使用禁漫本子号导入

v2.2.0 的 **添加书籍** 支持直接输入 18Comic 的纯数字本子号。桌面端可在“作品地址 / 禁漫本子号”中填写；Android 的导入选择器提供独立 **禁漫本子号** 入口。青卷会自动锁定漫画类型、使用完整下载模式，并获取专辑章节和图片。

请填写专辑编号而不是章节或图片编号。也可以继续使用受支持的完整专辑链接；输入与链接不一致、不是正整数或域名不可信时会拒绝导入。

## 导入 Legado 书源

青卷支持导入 Legado / 阅读 App JSON 书源。在 **书源管理** 页面可以：

- 粘贴书源配置；
- 从 URL 导入配置；
- 查看启用状态、类型、语言、标签和最近检查结果。

导入前请确认配置来源可信。书源规则能够引导后端访问外部 URL，不要导入来历不明、要求提交账号凭据或指向内网管理地址的配置。外部书源的导入、兼容性和启停状态不会出现在插件配置页。

## 搜索和加入书架

1. 打开 **搜索**；
2. 选择 **导入插件、书源、夸克、番茄、起点** 或 **笔趣阁**；
3. 输入书名、作者或关键词；
4. 从结果中确认作品来源、标题与类型；
5. 加入书架，并选择可用的下载策略；
6. 在 **任务中心** 查看后续进度。

搜索结果为空时，先确认对应站点插件或外部书源已启用，再检查当前后端网络和目标站点状态。

## 使用原则

- 只处理上游正常接口实际返回且能够验证的内容，不伪造账号、购买状态或响应；
- 遵守站点条款、robots 约定、版权要求和所在地法律；
- 控制并发，避免对第三方站点造成突发压力；
- 不在日志中记录账号 Cookie、正文、翻译密钥或连接 Token。

更完整的格式和站点清单见[支持范围](../reference/supported-sites.md)。
