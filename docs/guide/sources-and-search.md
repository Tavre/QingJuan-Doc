# 书源、插件与搜索

青卷使用两类能力发现作品和章节：随程序发布的 **站点解析插件**，以及用户导入的 **Legado / 阅读 App 书源规则**。两者都保存在当前后端中，但管理入口和数据模型相互独立。

## 内置站点解析插件

v1.7.0 起包含 22 个内置解析器，并公开名称、稳定 ID、版本、匹配域名、作品类型、能力、标签和启停状态：

- 小说与插画：番茄小说、起点中文网、夸克小说、Kakuyomu、Syosetu、Novel18、Hameln、Novelup、Alphapolis、Linovelib / Bilinovel、Pixiv；
- 漫画：18Comic、Bika Web App、Pixiv Comic、Yanmaga、Webtoons、Mangabz、漫画柜、拷贝漫画、COMICORES 漫核、动漫之家；
- 回退：通用网页解析器。

每个解析器的域名、能力和注意事项见[解析器总览](./parsers/)。网站结构、登录要求和地区策略可能变化；“内置支持”不表示每个作品在任何网络环境中都能永久下载。

### 在哪里管理插件

| 使用方式 | 管理入口 | 影响范围 |
| --- | --- | --- |
| Windows 本机后端 | Windows 左侧导航中的 **插件配置** | 只影响当前本机后端 |
| Windows Linux 远程模式 | Linux 管理界面的 **插件管理** | 影响连接该服务的全部客户端 |
| Android | 不显示客户端插件入口 | 由所连接 Linux 服务的管理员统一维护 |

插件页支持按名称或域名搜索、按启停状态筛选，并按小说、漫画和通用回退分组。当前唯一可编辑项是 **启用 / 停用**：插件随后端版本发布，不提供插件市场、安装、卸载、上传代码、在线更新或热加载。

停用插件后，后端会在发出新的第三方请求前拒绝对应预览、搜索和章节抓取；已经缓存到当前书库的章节仍可阅读。

## 选择搜索引擎

v1.7.0 搜索页提供四种引擎：

| 引擎 | 用途 |
| --- | --- |
| 书源 | 同时查询当前后端已启用且兼容搜索的 Legado / 阅读 App 书源 |
| 夸克 | 匿名查询夸克小说的书旗网页内核，只导入明确免费的完整章节 |
| 番茄 | 使用番茄小说匿名公开搜索，不要求先登录账号 |
| 起点 | 使用起点移动站公开搜索，不要求先登录账号 |

切换引擎会清空上一引擎的结果，避免混淆来源；每条结果仍会保留实际来源，加入书架时继续使用现有的作品链接导入流程。拷贝漫画和 COMICORES 的后端解析器也声明了公开搜索能力，但当前没有在主搜索页单列引擎入口。

### v1.7.1 夸克导入稳定性

Android 从夸克搜索结果加入书架时，会创建后台链接任务并轮询结果。界面会显示正在加入，并正确处理任务完成、失败、取消和等待超时；超时不表示任务已经被后端取消，仍可返回书架页查看进度。

后端会对夸克限流以及 HTTP 502 / 503 / 504 临时网关错误做有限次数重试，并短时复用同一作品的完整目录。若上游返回 HTML 错误页，客户端只显示可操作的 HTTP 错误，不会展示整页 HTML。免费章节边界没有改变。

## 番茄与起点账号书架

番茄小说和起点中文网支持账号登录与一键添加当前账号书架：

1. 先在 **插件配置** 或 `/admin/#plugins` 中启用对应插件；
2. 选择 **扫码登录**，使用站点官方 App 扫码并在手机上确认；
3. 番茄二维码在当前网络不可用时，可改用 **Cookie 登录**；起点只提供扫码登录；
4. 登录成功后选择 **添加账号书架**，在任务面板查看读取、去重、跳过、成功和失败数量。

导入会跨分组和分页去重，自动跳过青卷中已有的作品，并以“边看边下”模式添加新的文字作品。单本失败不会撤销已经成功添加的作品，同一插件同一时间只运行一个书架导入任务。

::: warning 登录凭据
站点 Cookie、会话与账号标识只保存在当前后端进程内存中，不写入数据库、普通日志、浏览器存储或客户端设置。后端重启后需要重新登录。不要在 Issue、截图或聊天中发送 Cookie。
:::

## 导入 Legado 书源

青卷支持导入 Legado / 阅读 App JSON 书源。在 **书源管理** 页面可以：

- 粘贴书源配置；
- 从 URL 导入配置；
- 查看启用状态、类型、语言、标签和最近检查结果。

导入前请确认配置来源可信。书源规则能够引导后端访问外部 URL，不要导入来历不明、要求提交账号凭据或指向内网管理地址的配置。外部书源的导入、兼容性和启停状态不会出现在插件配置页。

## 搜索和加入书架

1. 打开 **搜索**；
2. 选择 **书源、夸克、番茄** 或 **起点**；
3. 输入书名、作者或关键词；
4. 从结果中确认作品来源、标题与类型；
5. 加入书架，并选择可用的下载策略；
6. 在 **任务中心** 查看后续进度。

搜索结果为空时，先确认对应站点插件或外部书源已启用，再检查当前后端网络和目标站点状态。

## 使用原则

- 不绕过登录、购买、访问限制或已经结束公开访问的章节；
- 遵守站点条款、robots 约定、版权要求和所在地法律；
- 控制并发，避免对第三方站点造成突发压力；
- 不在日志中记录账号 Cookie、正文、翻译密钥或连接 Token。

更完整的格式和站点清单见[支持范围](../reference/supported-sites.md)。
