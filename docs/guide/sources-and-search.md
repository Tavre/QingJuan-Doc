# 书源、插件与搜索

青卷使用两类能力发现作品和章节：随程序发布的 **站点解析插件**，以及用户导入的 **Legado / 阅读 App 书源规则**。两者都保存在当前后端中，但管理入口和数据模型相互独立。

## 内置站点解析插件

当前内置支持范围包括：

- 小说：番茄小说、哔哩轻小说、Kakuyomu、Syosetu、Novel18、Pixiv；
- 漫画：Webtoon、拷贝漫画、动漫之家、18Comic、Bika。

当前源码把每个内置站点解析器注册为独立插件，并公开名称、稳定 ID、版本、匹配域名、作品类型、能力、标签和启停状态。网站结构、登录要求和地区策略可能变化；“内置支持”不表示每个作品在任何网络环境中都能永久下载。

### 在哪里管理插件

| 使用方式 | 管理入口 | 影响范围 |
| --- | --- | --- |
| Windows 本机后端 | Windows 左侧导航中的 **插件配置** | 只影响当前本机后端 |
| Windows Linux 远程模式 | Linux 管理界面的 **插件管理** | 影响连接该服务的全部客户端 |
| Android | 不显示客户端插件入口 | 由所连接 Linux 服务的管理员统一维护 |

插件页支持按名称或域名搜索、按启停状态筛选，并按小说、漫画和通用回退分组。当前唯一可编辑项是 **启用 / 停用**：插件随后端版本发布，不提供插件市场、安装、卸载、上传代码、在线更新或热加载。

停用插件后，后端会在发出新的第三方请求前拒绝对应预览、搜索和章节抓取；已经缓存到当前书库的章节仍可阅读。

## 导入 Legado 书源

青卷支持导入 Legado / 阅读 App JSON 书源。在 **书源管理** 页面可以：

- 粘贴书源配置；
- 从 URL 导入配置；
- 查看启用状态、类型、语言、标签和最近检查结果。

导入前请确认配置来源可信。书源规则能够引导后端访问外部 URL，不要导入来历不明、要求提交账号凭据或指向内网管理地址的配置。外部书源的导入、兼容性和启停状态不会出现在插件配置页。

## 搜索和加入书架

1. 打开 **搜索**；
2. 输入书名或关键词；
3. 从结果中确认作品来源、标题与类型；
4. 加入书架，并选择可用的下载策略；
5. 在 **任务中心** 查看后续进度。

搜索结果为空时，先确认对应站点插件或外部书源已启用，再检查当前后端网络和目标站点状态。

## 使用原则

- 不绕过登录、购买、访问限制或已经结束公开访问的章节；
- 遵守站点条款、robots 约定、版权要求和所在地法律；
- 控制并发，避免对第三方站点造成突发压力；
- 不在日志中记录账号 Cookie、正文、翻译密钥或连接 Token。

更完整的格式和站点清单见[支持范围](../reference/supported-sites.md)。
