# 翻译

青卷通过一套 OpenAI 兼容配置处理小说和漫画翻译。API 密钥保存在当前后端：Windows 本机模式保存在本机后端，远程模式保存在 Linux；客户端接口不会回传密钥明文。

## 配置翻译服务

Windows 本机模式在客户端 **设置 → 翻译服务** 中配置；Linux 远程模式使用安装时显示的浏览器管理地址，并打开 **模型设置**。Android 与 Windows 远程客户端只读取脱敏状态和触发后端自检，不保存模型密钥。

- 是否启用翻译模型；
- API 地址；
- API 密钥；
- 模型名称；
- 系统提示词；
- 自动翻译后续章节数；
- 下载并发数；
- 是否使用模型辅助识图。

青卷统一调用 OpenAI 兼容的 `/v1/chat/completions`。API 地址通常填写服务商给出的 `/v1` 根地址；具体模型名、额度和地区可用性以你的服务商说明为准。

::: warning 密钥安全
不要把 API 密钥写入截图、Issue、客户端日志、书源配置或文档示例。留空保存会保留服务端已有密钥；只有明确选择“清除”时才删除。
:::

## 模型端点安全

Linux 远程模式中，翻译模型和外部 OCR 设置只能由带 CSRF 校验的管理会话修改。Windows 本机模式则只接受受信回环客户端从应用内设置页写入；密钥不进入客户端偏好，也不从后端回显。普通远程客户端只能读取缓存后的模型状态，不能修改设置或触发真实外部探针。API 密钥与地址的协议、主机和端口绑定；切换到不同 Origin 时需要重新录入密钥。

模型和外部 OCR 请求默认只允许解析到公网地址的 HTTPS，并拒绝回环、私网、链路本地、保留地址、云元数据、环境代理和自动重定向。Linux 如需连接局域网中的自建模型，运维方必须精确授权 Origin：

```bash
sudoedit /etc/qingjuan/backend.env
```

例如加入：

```text
QINGJUAN_MODEL_ENDPOINT_ALLOWLIST=http://192.168.1.20:11434
```

多个 Origin 使用英文逗号分隔，随后执行 `sudo systemctl restart qingjuan-backend`。白名单不会通过管理 API 返回，也不要把其中的内部地址或凭据发布到 Issue。

## 小说翻译

小说章节会按任务处理，并保留原文。阅读器可在原文和译文之间切换；导出时，有有效译文则优先导出译文，否则回退到原文。

模型禁用、配置缺失或调用失败时，任务会停止并返回可操作错误，不会悄悄改用其他提供商。

## 漫画翻译

### Windows 漫画翻译工作台

v2.1.0 在 Windows 侧栏新增 **漫画翻译**。工作台既能使用本机后端，也能连接 Linux 远程后端；Android 暂不提供这套桌面工作区。

可以通过以下方式建立任务：

- 批量选择图片、递归选择文件夹，或把文件和文件夹拖入窗口；
- 点击 **从书架选择**，从漫画书籍中选择章节；
- 在漫画作品详情中直接点击翻译；未勾选章节时导入全部章节，勾选后只导入所选章节。

工作台提供九种流程：正常翻译、导出译文、导出原文、仅翻译工程 JSON、导入译文并渲染、仅上色、仅超分、仅修复和替换翻译。任务运行时可查看每个文件的状态，也可以停止批处理；已经完成的文件会保留。

默认工程目录为输入内容旁的 `manga_translator_work/`：工程 JSON 位于 `json/`，结果图位于 `result/`。导入译文或替换翻译时，可把同名图片放入 `translated_images/`；扩展名可以与原图不同。也可以为任务选择独立输出目录。

### 文本修改工作台

每张图片都可进入三栏编辑界面：左侧切换页面，中间核对原图、译图和文字框，右侧编辑原文、译文及横排/纵排方向。可以筛选尚未翻译的区域，也可以在原图上拖框补录 OCR 完全漏检的对白、标点或拟声词。

保存后会直接复用现有工程重新擦字、排版和渲染，不再次调用 OCR 或翻译模型。普通字段修改会保留字体、颜色和扩展信息；保存与渲染期间编辑区会锁定，返回页面时仍保留尚未保存的修改。

### 书架译文写回

来自书架的任务会保存准确的书籍、章节和页码绑定。整章所有页面成功后，结果图、逐页区域元数据和章节译文会写入书架的 **译文**；某一页失败时不会发布缺页章节，已经完成的其他章节仍可独立写入。

从文本工作台重新渲染书架页面后，青卷会重新组装完整章节并更新译文，无需再次调用 OCR 或翻译模型。若其他页面尚未生成工程或结果图，本地修改会保留，但不会覆盖书架中的完整章节；页面修改后未重新渲染时也会保持待处理标记。

默认流水线在当前后端执行：

1. RapidOCR 检测文字和坐标；
2. 按区域把纯文本发送给翻译模型；
3. 在原图中清除文字区域；
4. 按气泡或旁白框的安全区域重新排版译文。

本地 OCR 足够时，普通纯文本模型也可以完成漫画翻译。

v2.1.0 会严格核对模型逐区域返回结果：漏项或重复项会整批重试，原样返回的日文只重试对应区域。连续无法可靠翻译的裁切招牌或拟声片段会保留原图并记录区域编号，其余有效区域继续渲染，避免单个片段拖垮整页。

开启 **使用模型辅助识图** 后，青卷可能把漫画图片发送给明确支持视觉输入的模型，用于补充竖排字、小字、描边字和拟声词。只有在你理解数据流向且模型确实支持图片时才开启。

## 长译文和排版

青卷会尽量保留原文横排或竖排方向，并根据气泡安全区域调整字号和分列。译文超过容量时，会先请求模型在不丢失语义的前提下精简；仍无法容纳时，将完整文字图层等比缩放到安全区域内，不应截断或越过原气泡。

新工程会保存气泡框、安全框和区域样式，并根据未修改原图提取真实气泡内域。擦字与嵌字共用轮廓限制，减少凹形或相连气泡、分镜线和人物被误擦；旧工程只有 OCR 框时也会使用受限回退策略。无法可靠分离的气泡外网点字会保留原图，避免局部擦花。

## 排查失败

- `401` / `403`：检查翻译服务密钥和账户权限；
- `404`：检查 API 地址和模型名；
- `429`：检查额度、速率限制并降低并发；
- 超时或 `5xx`：通常是上游服务暂时不可用，可稍后重试；
- OCR 为空：确认当前后端的 RapidOCR 能力、图片质量和任务日志；
- 视觉调用失败：先关闭辅助识图，验证纯本地 OCR + 文本翻译路径。

任务日志会限制正文与凭据内容。需要向他人求助时，提供状态码、阶段、耗时和已脱敏错误即可。
