# 翻译

青卷通过一套 OpenAI 兼容配置处理小说和漫画翻译。API 密钥保存在当前后端：Windows 本机模式保存在本机后端，远程模式保存在 Linux；客户端接口不会回传密钥明文。

## 配置翻译服务

在当前后端管理界面的 **模型设置** 中配置。Windows 本机模式打开 `http://127.0.0.1:19453/admin/`；远程模式使用 Linux 安装时显示的管理地址。

- 是否启用翻译模型；
- API 地址；
- API 密钥；
- 模型名称；
- 系统提示词；
- 自动翻译后续章节数；
- 下载并发数；
- 是否使用模型辅助识图。

青卷统一调用 OpenAI 兼容的 `/v1/chat/completions`。API 地址通常填写服务商给出的 `/v1` 根地址；具体模型名、额度和地区可用性以你的服务商说明为准。

::: warning 密钥安全
不要把 API 密钥写入截图、Issue、客户端日志、书源配置或文档示例。留空保存会保留服务端已有密钥；只有明确选择“清除”时才删除。
:::

## 小说翻译

小说章节会按任务处理，并保留原文。阅读器可在原文和译文之间切换；导出时，有有效译文则优先导出译文，否则回退到原文。

模型禁用、配置缺失或调用失败时，任务会停止并返回可操作错误，不会悄悄改用其他提供商。

## 漫画翻译

默认流水线在当前后端执行：

1. RapidOCR 检测文字和坐标；
2. 按区域把纯文本发送给翻译模型；
3. 在原图中清除文字区域；
4. 按气泡或旁白框的安全区域重新排版译文。

本地 OCR 足够时，普通纯文本模型也可以完成漫画翻译。

开启 **使用模型辅助识图** 后，青卷可能把漫画图片发送给明确支持视觉输入的模型，用于补充竖排字、小字、描边字和拟声词。只有在你理解数据流向且模型确实支持图片时才开启。

## 长译文和排版

青卷会尽量保留原文横排或竖排方向，并根据气泡安全区域调整字号和分列。译文超过容量时，会先请求模型在不丢失语义的前提下精简；仍无法容纳时，将完整文字图层等比缩放到安全区域内，不应截断或越过原气泡。

## 排查失败

- `401` / `403`：检查翻译服务密钥和账户权限；
- `404`：检查 API 地址和模型名；
- `429`：检查额度、速率限制并降低并发；
- 超时或 `5xx`：通常是上游服务暂时不可用，可稍后重试；
- OCR 为空：确认当前后端的 RapidOCR 能力、图片质量和任务日志；
- 视觉调用失败：先关闭辅助识图，验证纯本地 OCR + 文本翻译路径。

任务日志会限制正文与凭据内容。需要向他人求助时，提供状态码、阶段、耗时和已脱敏错误即可。
