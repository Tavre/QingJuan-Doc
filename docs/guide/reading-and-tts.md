# 阅读与听书

青卷的阅读器同时面向 Windows 键鼠和 Android 触控。正文、译文与阅读进度来自当前选中的后端，界面主题和阅读偏好保存在当前设备。

## 阅读模式

- 左右分页与上下连续滚动；
- 覆盖、平移、淡入和无动画等分页效果；
- 原文与译文切换；
- 字号、行距、段落和章节进度调整；
- 白色、纸张、护眼、淡蓝和夜间配色；
- 章节目录、进度滑杆与快速跳转。

阅读器会预取相邻章节。连续滚动模式在缓存命中时可以直接衔接下一章；网络断开或章节尚未下载时会保留当前页面并给出可重试状态。

Android 还支持沉浸式系统栏和音量键阅读开关。v1.7.0 整理了手机宽度下的作品详情、听书和阅读控制层级，并统一触控尺寸、亮暗主题与安全区表现。减少动态效果或选择“无动画”后，翻页和界面过渡会尽量静止。

v1.7.1 缓存分页和文本测量结果，合并连续翻页产生的进度保存，并减少长章节滚动时的重复布局。分页动画改为轻量位移，阅读控制层不再使用高成本背景模糊。Android 优先请求同分辨率下不高于 120Hz 的最高显示模式；设备只提供更高档位时选择最接近 120Hz 的模式。这只是偏好请求，实际刷新率仍由系统设置、省电与温控策略决定。

## 漫画阅读

漫画按页面显示原图或已生成的译图。译图由 Windows 本机后端或 Linux 远程后端执行 OCR、分区翻译、原文清除与排版；Flutter 界面不会自行运行 OCR 模型。

翻译任务进行中时，任务中心可以逐页显示已完成的 OCR 原文与译文。失败页不会阻止已经完成的页面继续展示。

## 设备 TTS

听书使用 Windows 或 Android 的系统 TTS，不会在 FastAPI 后端合成声音。

在 **设置 → 听书声音** 中可以：

1. 重新扫描设备已安装的声音；
2. 选择系统默认声音或指定声线；
3. 试听当前声线；
4. 选择默认朗读风格。

自然或 Neural 声线通常比标准声线更接近真人，但可用性由设备系统和已安装语言包决定。朗读风格会调整节奏、停顿和语调，不会把标准音色变成新的语音模型。

## 数据同步边界

| 数据 | 保存位置 |
| --- | --- |
| 作品、章节、译文、阅读进度 | 当前选中的 Windows 本机后端或 Linux 远程后端 |
| 主题、字号、阅读方式、TTS 声线偏好 | 当前客户端设备 |
| 远程连接 Token | 当前设备的平台安全存储；本机模式不需要 Token |

更换手机后需要重新配置服务地址和 Token；连接同一 Linux 服务后可以重新读取远程书架。Windows 本机书库位于解压目录的 `backend/data/`，不会自动同步到远程后端。
