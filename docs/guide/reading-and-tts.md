# 阅读与听书

青卷的阅读器同时面向 Windows 键鼠和 Android 触控。正文、译文与阅读进度来自当前选中的后端，界面主题和阅读偏好保存在当前设备。

Android 通过 v2.2.0 的局域网二维码连接 PC 后，会读取并写回 PC 本机后端中的同一份阅读进度；连接 Linux 时仍按登录账号同步。更换后端不会自动把进度迁移到另一套书库。

v2.1.0 奠定了 Android 触控布局；v2.3.0 的主要入口为“书库、推荐、搜索、任务、我的”，手机使用紧凑液态胶囊底栏，平板使用移动侧栏与作品/目录双栏。继续阅读会直接进入正文，浅色、深色与跟随系统主题位于 **我的 → 外观**。

## 阅读模式

- 左右分页与上下连续滚动；
- 覆盖、平移、淡入和无动画等分页效果；
- 原文与译文切换；
- 字号、行距、段落和章节进度调整；
- 小说段落使用两字首行缩进和两端对齐；
- 白色、纸张、护眼、淡蓝和夜间配色；
- 章节目录、进度滑杆与快速跳转。

阅读器会预取相邻章节。连续滚动模式在缓存命中时可以直接衔接下一章；网络断开或章节尚未下载时会保留当前页面并给出可重试状态。

Android 还支持沉浸式系统栏和音量键阅读开关。v1.7.0 整理了手机宽度下的作品详情、听书和阅读控制层级，并统一触控尺寸、亮暗主题与安全区表现。减少动态效果或选择“无动画”后，翻页和界面过渡会尽量静止。

v1.7.1 缓存分页和文本测量结果，合并连续翻页产生的进度保存，并减少长章节滚动时的重复布局。分页动画改为轻量位移，阅读控制层不再使用高成本背景模糊。Android 优先请求同分辨率下不高于 120Hz 的最高显示模式；设备只提供更高档位时选择最接近 120Hz 的模式。这只是偏好请求，实际刷新率仍由系统设置、省电与温控策略决定。

v1.7.2 调整 Linux 远程后端的章节准备顺序：按需导入后会在后台顺序缓存全部可访问章节，但用户打开的当前章和下一章始终优先。同一章节的并发请求会合并，后台单章失败不会阻断后续缓存。Windows 本机后端继续采用当前章与相邻章的轻量策略。

v1.7.4 统一了分页、上下滚动和 Windows 阅读器的小说段落排版：客户端会清理站点原有的段首空白，再应用稳定的两字首行缩进和两端对齐；自动换行和跨页续行不会重复缩进。

v1.7.5 不再使用会参与字体整形的不可见字符模拟缩进，而是让分页、上下滚动和 Windows 阅读器共享固定两字宽的布局占位。这样可以避免两端对齐拉伸缩进，短段和长段的首行也不会因缩进字符宽度不同而漂移。

v1.7.6 进一步让连续模式与 Windows 阅读器的每个正文项占满同一阅读栏：无论段落长短、设备字体或自动换行结果，首个正文字符都位于相同的页面横坐标。两字缩进会随系统文字缩放同步变化，换行和跨页续行仍从正文左边界开始。

Android 阅读器打开后会隐藏顶部时间状态栏，但保留底部导航或手势区。v1.7.6 会让当前阅读背景覆盖状态栏、窗口和刘海短边区域，并在窗口重新获焦、应用恢复前台或切换阅读配色后重新应用隐藏状态，减少 ColorOS、MIUI 等系统重置界面后出现顶部黑条的情况。退出阅读器或进入听书时会恢复宿主页面的系统栏状态。

开启“音量键滑动 / 翻页”后，分页模式使用音量键切换页面，连续模式按约一屏距离移动；到达章节边界时，同一次按键会等待相邻章节装入并继续阅读。

## 书签、笔记与正文搜索

v2.3.0 的阅读器顶部提供 **书签、笔记与搜索**。连续和分页阅读均可选中文字保存带摘录的位置笔记，再次打开章节时显示对应划线；正文发生变化时会提示重新核对，不会把笔记错误定位到相似句子。搜索支持当前章和全书范围，只扫描后端已缓存的原文或译文，不会为了搜索自动下载章节。

## 漫画阅读

漫画按页面显示原图或已生成的译图。译图由 Windows 本机后端或 Linux 远程后端执行 OCR、分区翻译、原文清除与排版；Flutter 界面不会自行运行 OCR 模型。

翻译任务进行中时，任务中心可以逐页显示已完成的 OCR 原文与译文。失败页不会阻止已经完成的页面继续展示。

## 设备 TTS

听书使用 Windows 或 Android 的系统 TTS，不会在 FastAPI 后端合成声音。

在 **设置 → 听书声音** 中可以：

1. 重新扫描设备已安装的声音；
2. 选择系统默认声音或指定声线；
3. 试听当前声线；
4. 选择默认朗读风格。

自然或 Neural 声线通常比标准声线更接近真人，但可用性由设备系统和已安装语言包决定。朗读风格会调整节奏、停顿和语调，不会把标准音色变成新的语音模型。

v2.3.0 会独立保存听书位置，并可设置定时停止。Android 支持通知栏和锁屏媒体控制，应用进入后台后仍可继续播放；切换账号、书籍或后端时会切换到对应的听书状态。

## Android 离线阅读

Android 可在作品详情选择章节保存到设备。离线副本按服务实例和账号隔离；断网时可以阅读已保存章节，阅读进度会留在设备，恢复联网后自动提交。若其他设备已经推进进度，客户端会显示冲突并由用户选择保留本机或服务端位置。清理离线内容不会丢弃尚未同步的进度。

## 数据同步边界

| 数据 | 保存位置 |
| --- | --- |
| 作品、章节、译文、阅读进度 | 当前选中的 Windows 本机后端或 Linux 远程后端 |
| 主题、字号、阅读方式、TTS 声线偏好 | 当前客户端设备 |
| Android 离线章节、待同步进度与听书位置 | 当前设备，按后端和账号隔离 |
| 远程连接 Token | 当前设备的平台安全存储；本机模式不需要 Token |

更换手机后需要重新配置服务地址和 Token；连接同一 Linux 服务后可以重新读取远程书架。Windows 本机书库位于解压目录的 `backend/data/`，不会自动同步到远程后端。
