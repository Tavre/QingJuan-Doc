# 选择与连接后端

Windows 支持 **本机后端** 和 **Linux 远程后端**；Android 只支持 Linux 远程后端。两种模式使用独立数据，切换时不会自动迁移或同步书库。

## Windows 本机后端

只在当前 Windows 电脑上使用青卷时：

1. 打开 **设置 → 后端连接**；
2. 选择 **本机后端**；
3. 点击 **保存设置**。

应用会检查并按需启动安装包内的 `backend/qingjuan-desktop.exe`。本机模式：

- 固定使用 `http://127.0.0.1:19453`；
- 无需 Linux 服务器；
- 无需连接 Token；
- 无需另外安装 Python；
- 数据保存在完整解压目录的 `backend/data/`；
- 管理界面位于 `http://127.0.0.1:19453/admin/`。

离开本机模式或退出应用时，青卷只回收由当前客户端启动的本机后端进程。端口已被其他程序占用或后端不兼容时，会显示明确错误，不会终止不属于青卷的进程。

## Linux 远程后端

Android，或希望多台设备共用书库时，需要 FastAPI 根地址和连接 Token。两者由 Linux 安装脚本生成，可再次查看：

```bash
sudo qingjuan-info
```

Windows 在设置中选择 **Linux 远程后端**；Android 直接填写远程连接信息。

v1.7.4 的 Android 设置页在 Token 密码框旁增加了明确的 **粘贴** 按钮，适用于系统长按菜单无法粘贴的设备。按钮只把纯文本写入当前输入框，不会记录、回显或上传剪贴板内容。

### 地址应该怎么填

可用示例：

```text
http://192.168.1.20:19453
http://100.64.10.20:19453
https://reader.example.com
```

- `192.168.x.x`、`10.x.x.x` 等局域网地址可使用 HTTP；
- Tailscale、WireGuard 等可信私有网络地址可使用 HTTP；
- 任何公网地址都必须通过 HTTPS 访问。

不要填写带 `/api/v1`、用户名、密码、查询参数或片段的 URL，也不要使用未配置 TLS 的公网 HTTP 地址。远程客户端中的 `127.0.0.1` 指向客户端自己，不是另一台 Linux 主机。

## Token 与管理密码不是一回事

| 凭据 | 用在哪里 | 用途 |
| --- | --- | --- |
| 连接 Token | Windows 远程模式 / Android | 认证 `/api/v1` 客户端 API |
| 管理密码 | Linux 浏览器管理界面 | 登录 `/admin/` 管理会话 |
| 翻译 API 密钥 | 当前后端的管理界面 | 调用配置的 OpenAI 兼容服务 |

Windows 本机模式不需要连接 Token，本机回环管理会话也不要求 Linux 管理密码。

## 连接状态

- **正在启动本机后端**：Windows 正在检查或启动随包后端；
- **本机后端已连接**：Windows 正在使用本机书库；
- **首次使用需要连接服务器**：远程地址或 Token 尚未保存；
- **正在检查 Linux 后端**：正在校验服务标识、API 版本和能力；
- **Linux 后端已连接**：可以加载远程书架、书源和任务；
- **本机后端启动失败 / Linux 后端连接失败**：保留设置与重试入口，不会自动切换模式。

切换模式成功后，客户端会停止旧轮询、清理旧页面状态，再加载所选后端的书库。远程地址和 Token 会保留，不会因切换到本机模式而被清空。

## 远程连接检查

在 Linux 服务器上：

```bash
sudo systemctl status qingjuan-backend --no-pager
curl --fail http://127.0.0.1:19453/healthz
sudo qingjuan-info
```

健康检查正常但客户端返回 `401` 时，通常是连接 Token 不匹配；网络超时则优先检查地址、路由、防火墙和反向代理。

::: warning 不要为排障泄露凭据
日志、截图和 Issue 中只保留地址的主机部分和错误状态。连接 Token、管理密码、Cookie、翻译密钥与正文都应移除。
:::
