# 选择与连接后端

Windows 支持 **本机后端** 和 **Linux 远程后端**。Android 不在手机内运行后端，可以连接 Linux 服务，也可以在 v2.2.0 中扫描二维码连接同一局域网内 PC 共享的本机后端。Windows 本机数据与 Linux 数据仍然独立，切换时不会自动迁移或同步书库。

## Windows 本机后端

只在当前 Windows 电脑上使用青卷时：

1. 打开 **设置 → 后端连接**；
2. 选择 **本机后端**；
3. 点击 **保存设置**。

应用会检查并按需启动安装包内的 `backend/qingjuan-desktop.exe`。本机模式：

- 固定使用 `http://127.0.0.1:19453`；
- 无需 Linux 服务器；
- 无需连接 Token；
- 无需另外安装 Python；
- 数据保存在完整解压目录的 `backend/data/`；
- 直接在客户端 **设置 → 翻译服务** 中维护模型与外部 OCR；
- 不提供浏览器管理界面，也不显示注册、登录、GitHub 或 2FA 入口。

离开本机模式或退出应用时，青卷只回收由当前客户端启动的本机后端进程。端口已被其他程序占用或后端不兼容时，会显示明确错误，不会终止不属于青卷的进程。

## 手机扫码连接 PC

v2.2.0 允许 Android 使用 Windows 当前连接的后端：

1. 手机和电脑连接同一可信局域网；
2. PC 在 **设置 → 后端连接** 中保存并连接后端；
3. 打开 **设置 → 手机连接**；本机模式下选择手机所在的内网网卡；
4. 点击 **生成连接二维码**；Windows 防火墙询问时只允许专用网络；
5. Android 打开 **我的 → 服务连接 → 扫描二维码**，核对显示的地址并连接。

无法使用相机时，可在 PC 点击 **复制连接链接**，再粘贴到 Android。支持青卷应用链接的扫码软件也可直接唤起客户端。

### PC 使用本机后端

青卷会在所选内网地址的 TCP `19454` 端口开启带独立连接密钥的共享入口。Android 使用 PC 的同一份书库、任务、阅读进度和翻译配置，不需要 Linux，也不需要另建青卷账号。

- PC 青卷必须保持运行，收起到托盘可以继续共享；
- 点击 **关闭共享**、切换 PC 到远程模式或退出 PC 青卷后，入口失效；
- 点击 **重新生成二维码** 会轮换密钥，已连接手机需要使用新二维码；
- 多网卡电脑应选择与手机处于同一网段的 Wi-Fi 或有线网卡；
- 二维码和链接包含连接凭据，只应提供给可信设备。

### PC 使用 Linux 远程后端

二维码会分享 PC 当前保存的 Linux 地址和连接 Token。Android 连接后仍需登录该 Linux 服务中的用户账号；只有使用相同账号时，才会看到与 PC 相同的远程书架。隐藏二维码不会撤销服务器 Token，如怀疑泄露应在服务器轮换 Token。

## Linux 远程后端

希望后端长期在线、从外网通过 HTTPS 访问，或让多个账号使用隔离书库时，需要 Linux FastAPI 根地址和连接 Token。两者由安装脚本生成，可再次查看：

```bash
sudo qingjuan-info
```

Windows 在设置中选择 **Linux 远程后端**；Android 可手动填写连接信息，也可扫描一台已连接该服务的 PC 所生成的二维码。

v2.0.0 的连接 Token 只负责进入服务器。连接成功后还要在 **我的** 中注册或登录；每个用户拥有独立书架、阅读进度和任务。同一账号可在多台设备登录，不同账号不会共享个人书库。

v1.7.4 的 Android 设置页在 Token 密码框旁增加了明确的 **粘贴** 按钮，适用于系统长按菜单无法粘贴的设备。按钮只把纯文本写入当前输入框，不会记录、回显或上传剪贴板内容。

### 地址应该怎么填

可用示例：

```text
http://192.168.1.20:19453
http://100.64.10.20:19453
https://reader.example.com
```

- `192.168.x.x`、`10.x.x.x` 等局域网地址可使用 HTTP；
- Tailscale、WireGuard 等可信私有网络地址可使用 HTTP；
- 任何公网地址都必须通过 HTTPS 访问。

不要填写带 `/api/v1`、用户名、密码、查询参数或片段的 URL，也不要使用未配置 TLS 的公网 HTTP 地址。远程客户端中的 `127.0.0.1` 指向客户端自己，不是另一台 Linux 主机。

## Token 与管理密码不是一回事

| 凭据 | 用在哪里 | 用途 |
| --- | --- | --- |
| 连接 Token | Windows 远程模式 / Android / PC 局域网共享 | 允许客户端进入指定后端；二维码可携带受保护连接信息 |
| 用户账号与会话 | 远程客户端的“我的” | 标识当前用户及其独立书架 |
| 管理密码 | Linux 浏览器管理界面 | 登录 `/admin/` 管理会话 |
| 翻译 API 密钥 | Windows 本机客户端设置或 Linux 管理界面 | 调用配置的 OpenAI 兼容服务 |

Windows 本机模式不需要连接 Token、用户账号或 Linux 管理密码。

## 连接状态

- **正在启动本机后端**：Windows 正在检查或启动随包后端；
- **本机后端已连接**：Windows 正在使用本机书库；
- **首次使用需要连接服务器**：远程地址或 Token 尚未保存；
- **正在检查 Linux 后端**：正在校验服务标识、API 版本和能力；
- **Linux 后端已连接**：可以进入登录或注册流程，登录后加载当前账号的书架；
- **PC 局域网后端已连接**：Android 正在通过局域网使用 Windows 本机书库，不要求用户账号；
- **本机后端启动失败 / Linux 后端连接失败**：保留设置与重试入口，不会自动切换模式。

切换模式成功后，客户端会停止旧轮询、清理旧页面状态，再加载所选后端的书库。远程地址和 Token 会保留，不会因切换到本机模式而被清空。

## 远程连接检查

在 Linux 服务器上：

```bash
sudo systemctl status qingjuan-backend --no-pager
curl --fail http://127.0.0.1:19453/healthz
sudo qingjuan-info
```

健康检查正常但客户端返回 `401` 时，通常是连接 Token 不匹配；网络超时则优先检查地址、路由、防火墙和反向代理。

::: warning 不要为排障泄露凭据
日志、截图和 Issue 中只保留地址的主机部分和错误状态。连接 Token、管理密码、Cookie、翻译密钥与正文都应移除。
:::
