# 管理界面

FastAPI 后端随同源码提供 React 管理界面，用于管理 Linux 远程后端。v2.0.0 的 Windows 本机后端不再挂载 `/admin/`；本机模型与 OCR 在客户端设置中维护。管理界面不是阅读器，也不是 PWA。

## 打开管理界面

运行：

```bash
sudo qingjuan-info
```

在浏览器打开输出中的管理地址，通常是 FastAPI 根地址后加 `/admin/`。使用安装完成时生成的管理密码登录。

## 页面

| 页面 | 作用 |
| --- | --- |
| 服务概览 | 查看后端、书库与任务状态；开启、关闭或重启业务服务 |
| 用户管理 | 创建或停用用户、维护资料与角色、重置密码并撤销会话 |
| 注册设置 | 配置邮箱验证码、固定身份牌、SMTP 和 GitHub Device Flow |
| 书库管理 | 查看作品、类型、语言、章节和状态，并确认删除操作 |
| 任务中心 | 跟踪下载与翻译任务、查看脱敏诊断日志 |
| 书源状态 | 查看启用书源、类型、语言、标签和最近检查 |
| 插件管理 | 管理内置与导入解析器；导入、更新或卸载可信插件包；使用支持的站点登录与书架能力 |
| 模型设置 | 维护翻译模型、OCR 辅助选项和并发参数 |
| 后端升级 | 检查并安装受信部署仓库中的后端更新，查看恢复状态 |

管理界面查看的是全局服务资源。用户书架、阅读进度和任务按账号隔离；书源、解析器、模型设置及 Bika 抓取凭据属于服务级配置，修改后会影响所有用户。Windows 本机书库与 Linux 书库不会自动同步。

v1.7.2 起，翻译模型和外部 OCR 设置只能由管理会话修改，所有写入都校验 CSRF。普通客户端 Token 不能修改设置或触发真实外部探针。模型密钥与地址 Origin 绑定；协议、主机或端口改变后，需要重新录入密钥。Linux 局域网模型的精确白名单只能由运维方修改 `/etc/qingjuan/backend.env`，不会显示在管理界面中。

v2.0.0 增加用户、注册和在线升级页面。用户角色、密码或状态变化会立即撤销旧客户端会话；内置 `admin` 不能停用或降权。注册设置与客户端账号安全操作见[用户与注册](./users-and-registration.md)。

插件管理可通过 `/admin/#plugins` 直接打开。它允许修改解析器启停状态，并为番茄和起点提供扫码登录与账号书架导入；番茄还提供 Cookie 登录兜底，v2.2.0 的少年梦提供受控浏览器账号登录。

v2.2.0 起，管理员还可预检、安装、更新和卸载 `.qjplugin` / `.zip` 站点插件包。导入包是运行在后端进程内的 Python 代码，不是沙箱；只安装来源可信且经过审查的插件。Windows 本机模式可在 Flutter 客户端的 **插件配置** 页面完成同类管理，Android 只能使用当前后端已经安装的插件。

服务概览中的 **开启服务、关闭服务、重启服务** 只控制客户端业务 API 与新队列任务，管理通道保持在线。关闭前会提示活动任务；写操作要求管理会话和 CSRF，因此管理员可以停用业务后继续在同一页面恢复。

站点登录凭据只保存在当前后端进程内存中，不写入数据库或浏览器存储。后端重启后需要重新登录；书架导入任务会保留新增、跳过和失败统计，但不会记录 Cookie。

## 修改或重置密码

交互式修改：

```bash
sudo qingjuan-password
```

生成新的随机密码：

```bash
sudo qingjuan-password --generate
```

改密会重启服务并使已有管理会话失效。新密码只在终端显示，请立即保存到可信密码管理器。

## 管理认证边界

- 管理密码只用于 `/admin/`，不能作为客户端连接 Token；
- 服务端保存密码的慢哈希，不通过 API 回传明文；
- 浏览器使用 HttpOnly、SameSite 会话 Cookie；
- 写操作校验 CSRF；
- 登录失败会受到限制，避免无限尝试；
- 管理界面必须和 API 处于相同的可信私网或 HTTPS 保护下。

## 登录失败

1. 确认访问的是 `/admin/`，不是 FastAPI 文档或 `/api/v1`；
2. 确认输入的是管理密码，不是连接 Token；
3. 清除该站点的旧 Cookie，重新打开登录页；
4. 忘记密码时使用 `sudo qingjuan-password --generate`；
5. 查看 `sudo journalctl -u qingjuan-backend -f`，但不要复制 Cookie、密码或配置值。
